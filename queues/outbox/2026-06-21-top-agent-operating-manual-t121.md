# Top Agent Operating Manual — T-121

Codex создал `docs/top-agent-operating-manual.md`.

Зачем: нужен чистовой документ для человека или агента на "вершине пирамиды", который подключается к системе и должен понять не историю разработки, а текущие функции, правила, автоматизацию, ограничения и дальнейшие пути развития.

В документе есть:

- metadata-блок;
- карта функций;
- инструкция для агента;
- Q&A по вопросам Stefan;
- оценка self-improvement;
- проблемы коллективной работы и методы решения;
- микро-инструкции;
- предложения по дальнейшей автоматизации.

Моё мнение: это должен стать один из главных входов для новых агентов вместе с `docs/bridge-usage.md` и `docs/layers-coverage.md`.

Примечание по синхронизации: параллельно существует `docs/agent-onboarding.md`. Он оставлен как основной человеко-читаемый онбординг, а `docs/top-agent-operating-manual.md` — как операционный manual с командами и micro-skills. Документы связаны взаимными ссылками.
