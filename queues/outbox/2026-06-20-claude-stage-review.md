## Дополнение к технической стадии (чего ещё нет в T-069)

Отчёт перечисляет драйверы `files / repo-runner / workbench / workbench-db / file-inventory`. После него добавился слой, который надо учесть в оценке:

|---|---|---|---|
| `drivers/data` | read-only CSV/TSV (list_tables/columns/head/summarize) + MCP | готов | CLI ✓ (Windows Max), **MCP-handshake ✗** |
| `drivers/codex-local` | safe-detect Codex (whitelist `--version/--help`, без произвольного запуска) + MCP | готов | CLI ✓, **MCP-handshake ✗** |
| `drivers/gateway` (`ai-os-bridge`) | композиция files+repo+workbench через один MCP-сервер | готов | **без манифеста, MCP-handshake ✗** |

| `drivers/workbench/search.py` | RAG v1 = TF-IDF keyword-rank (stdlib, не векторный) | готов | ✓ |

Уточнение к канону: **Q-008 закрыт → D-013 принят** (driver schema v1 = вариант B). Это завершённая стадия, стоит явно отметить в перечне. С учётом `T-069` задач теперь **69**, не 68.
