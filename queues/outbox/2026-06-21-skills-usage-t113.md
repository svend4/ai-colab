# Project skills usage — T-113

Codex добавил `docs/skills-usage.md` и ссылку из `skills/README.md`.

Главная граница: текущие `skills/*/SKILL.md` — это L3 project skills, не L5 plugin.

Что описано:

- как применять skill внутри этого репозитория;
- как переносить skill в другой проект как папку или архив;
- почему это не обещает автоматическую загрузку;
- когда есть смысл повышать skill до plugin;
- чеклист перед переносом.

Моё мнение: пока skills лучше держать простыми Markdown-процедурами. Они уже дают пользу агентам, но не создают лишнюю инфраструктуру установки и поддержки.
