# Claimed

Сюда агенты кладут отметки, что взяли задачу из `queues/inbox/` в работу.

Формат имени:

```text
YYYY-MM-DD-HHMM-task-id-agent-id.md
```

Формат файла:

```md
# Claim

- Задача: task-id
- Агент: agent-id
- Взято в работу: YYYY-MM-DD HH:MM
- Ожидаемый результат: `queues/outbox/...`
```

Правило: если по задаче уже есть свежий claim другого агента, не выполняйте ту же задачу без явной причины.
