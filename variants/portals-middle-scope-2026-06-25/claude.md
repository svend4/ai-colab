# 0. Визитка
> Триада охвата требует СРЕДНЕГО слоя: не прыгать «агент → сразу глобал», а сводить родственные
> варианты в КЛАСТЕР/ПОРТАЛ сначала, потом порталы — в глобал (золотая середина И-8). Эта тула строит
> граф похожести вариантов ПО СОДЕРЖАНИЮ (не по генотипу — это другая ось, чем independence_measure) и
> режет на связные компоненты = порталы. Как ньюс-группы: варианты сами оседают по темам.

# 1. Условия применимости
Когда вариантов МНОГО и они про РАЗНЫЕ темы — нужен средний слой, чтобы сверка не была «все против всех».
При <= нескольких вариантах одной темы портал тривиален (один). Похожесть — по содержанию, не генотипу.

# 2. Проблема
Прыжок агент→глобал: при росте числа вариантов сверка «каждый с каждым» взрывается и мешает темы.
Нужен средний слой (И-8): родственное сводится локально (портал) до глобального консенсуса.
Это «золотая середина должна присутствовать везде» — конкретно в ОХВАТЕ.

# 3. Дизайн
- **3.1. Узлы** = варианты; **рёбра** = пара с content-похожестью (Jaccard токенов тела) >= порог.
  Это ТЕМАТИЧЕСКАЯ близость (другая ось, чем клон-похожесть independence_measure: генотип+поверхность).
- **3.2. Порталы** = связные компоненты графа (union-find). Каждый портал — средняя единица сверки.
- **3.3. Маршрут:** сверка ВНУТРИ портала (родственные варианты) → консенсус портала → порталы в глобал.
- **3.4. Как ньюс-группы:** варианты оседают по темам автоматически, без ручного назначения тем.

# 4. Уникальный вклад
- **Средний слой охвата построен** (И-8) — триада агент·портал·глобал замкнута; «золотая середина» в охвате.
- **Тематическая ось ОТДЕЛЕНА от клон-оси**: portals (содержание = тема) vs independence_measure
  (генотип = свидетель). Две разные похожести для двух разных вопросов.
- **Автокластеризация по темам** (ньюс-группы) без ручных меток.

# 5. Evidence
И-8 (мой вклад в kotel) + сквозная тема Stefan «кластеры/порталы как ньюс-группы, золотая середина
везде». consensus_by_meaning работает на ОДНОЙ теме — портал даёт ему вход среднего масштаба.

# 6. Риски
- Порог содержания произволен → параметр + дефолт; слишком низкий → всё в один портал, слишком высокий → атомизация.
- Общая лексика методички может слить разные под-темы в один портал → это находка (значит тема одна), не баг.

# 7. Инварианты
- **PT-1** Похожесть портала — по СОДЕРЖАНИЮ (тема), не по генотипу.
- **PT-2** Сверка сперва ВНУТРИ портала, потом порталы в глобал (не прыгать агент→глобал).
- **PT-3** Кластеризация автоматическая (ньюс-группы), без ручных меток.
