# 0. Визитка
> doc_consensus.py: консенсус = claim в ≥2 документах (СЧЁТ). Котёл потребовал заменить это отбором по
> смыслу. Эта тула: claim взвешивается ЭФФЕКТИВНЫМИ СВИДЕТЕЛЯМИ (independence_measure), а не вхождениями.
> Claim в 3 клон-вариантах = 1 свидетель → минор; claim в 2 НЕЗАВИСИМЫХ → 2 свидетеля → ядро. Выход —
> 3 слота (ядро · scope-ветви · минор), а не binary. Денежный кадр: «3 вхождения, но 1 свидетель».

# 1. Условия применимости
Сведе́ние ≥2 ripe-вариантов (после ripeness_gate) одной темы. НЕ для механики. Лексическая канонизация
claim сейчас (груба к синонимам) — настоящая смысловая канонизация = несущая стена №1 (LLM), подключаема.

# 2. Дизайн
- **2.1. Извлечь атомарные claim** каждого варианта (буллеты/заголовки/строки) с тегом источника.
- **2.2. Кластеризовать claim по смыслу** (сейчас лексически, порог; КАНОНИЗАЦИЯ ПОДКЛЮЧАЕМА — стена №1).
- **2.3. Взвесить кластер ЭФФЕКТИВНЫМИ СВИДЕТЕЛЯМИ:** support = множество вариантов, давших claim;
  strength = `independence_measure.effective_witnesses(support)` — НЕ `len(support)`. Клоны схлопнуты.
- **2.4. 3-слотный выход:** ядро (свидетелей ≥2) · минор (свидетель =1, СОХРАНЁН) · scope-ветви
  (противоречия — требуют смысловой канонизации, стена №1 → пока флаг, не авто-разрешение).

# 3. Уникальный вклад
- **Композиция: первая тула, где «сила = эффективные свидетели, не count».** Прямая замена логики
  `len(docs)>=2`. Переиспользует independence_measure (чистая архитектура, не дублирует).
- **Подключаемая канонизация** изолирует стену №1: лексика сейчас не блокирует, LLM позже без переписи.
- **Контраст count↔свидетели в выводе** («3 вхождения, но 1 свидетель») делает разницу видимой человеку.

# 4. Риски
- Лексическая кластеризация грубо (синонимы) → стена №1 уточнит; сейчас флажить, не врать о точности.
- Детект противоречий (scope-ветви) без семантики невозможен → честно: 2 из 3 слотов детерминированы,
  3-й (scope) помечен как нужный стене №1.
- Свидетель=1 ≠ неверно: минор СОХРАНЯЕТСЯ (инвариант), не отбрасывается.

# 5. Evidence
Котёл-ядро п.1 (счёт отменён), п.3 (независимость взвешивает), п.4 (минор-сохранить), п.6 (3 слота).
