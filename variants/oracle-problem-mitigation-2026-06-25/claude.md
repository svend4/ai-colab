# 0. Визитка
> Self-repair вскрыл общий корень 7 still-refuted: любой семантический шаг (канонизация, судья,
> опровержение) упирается в ОДНОГО LLM = захватываемая точка (judge-capture). Оракула НЕ устранить с LLM.
> Но можно: (1) поднять цену захвата 1→кворум независимых судей; (2) сделать захват ВИДИМЫМ (рассогласие
> судей = сигнал); (3) заменить захватываемые эвристики проверяемым ПРОВЕНАНСОМ там, где можно (seal-порядок
> вместо поверхности). Честность: смягчение + детекция, НЕ решение.

# 1. Условия применимости
Для всех семантических гейтов (verdict, канонизация, опровержение). НЕ для механики (там оракул не нужен).
Остаточная LLM-зависимость ПРИЗНаётся, не прячется.

# 2. Проблема (из self-repair, kotel §10)
prose-vs-code: ремонты добавляют гейты прозой, но `red_team_gate.gate()` маршрутизирует по ОДНОМУ полю
verdict от ОДНОГО LLM. «По смыслу не числом» схлопывается в «один LLM сказал». Захват судьи = захват всего.
Симметрично: метод требует независимости для СВИДЕТЕЛЕЙ, но даёт решающую власть ОДНОМУ судье.

# 3. Дизайн — два столпа
- **3.1. Кворум независимых судей (`oracle_quorum.py`).** Вердикт НЕ от 1 LLM, а от N НЕЗАВИСИМЫХ
  (разные model/lens/seed). Кворум решает; РАССОГЛАСИЕ судей → contested (захват/неоднозначность ВИДИМЫ),
  не молча. Цена захвата 1→⌈N/2⌉ независимых — та же защита, что для свидетелей (самосогласовано).
- **3.2. Seal-провенанс независимости (фикс `independence_measure`).** Две ОРТОГОНАЛЬНЫЕ оси (урок атаки
  blindness): провенанс (sealed-blind = писал до экспозиции) И генотип-декорреляция. Тогда:
  - тот же генотип → клон (1.0), даже sealed (эхо весов — слепота не спасает);
  - разный генотип + оба sealed-blind → НЕЗАВИСИМЫ (0.0), даже surf=1.0: провенанс доказывает «не копия»
    (чинит терсную-истину «срок 30 дней» из остатка independence-weight);
  - разный генотип + НЕ оба sealed → поверхность может ловить копию (COPY_THR).
- **3.3. Типизация суждений** (из выжившего falsifiability): эмпирический claim → тест; нормативный →
  адверсариальная демонстрация. Разный оракул под разный класс.

# 4. Уникальный вклад
- **Симметрия судья↔свидетель**: метод не доверял 1 свидетелю — теперь не доверяет и 1 судье (кворум).
  Закрывает reason-not-vote на УРОВНЕ КОДА, не прозы.
- **Провенанс > эвристика**: независимость по проверяемому seal-порядку (факт), не по захватываемой
  поверхности (суждение). Чинит терсную-истину.
- **Детекция захвата**: рассогласие судей — наблюдаемый сигнал; 1 судья делал захват невидимым.
- **Честность остатка**: оракул смягчён, не устранён — заявлено явно (не prose-vs-code обман).

# 5. Evidence
kotel §10 (корень 7 still-refuted). reason-not-vote-атака сама дала рецепт: «подделать K свидетелей =
скомпрометировать ⌈K/2⌉, дорого и видимо» — применяю ТО ЖЕ к судье. independence-weight-остаток: нужна
провенанс/семантика, не поверхность — seal даёт провенанс. REFUTE_QUORUM=2 в red_team_gate — уже зачаток.

# 6. Риски
- N судей — те же LLM → коррелированы, если одна модель. Смягчение: требовать РАЗНЫЕ model/lens (как
  independence_measure меряет у свидетелей). Остаток признан.
- Seal можно подделать (написать sealed:blind ложно) → нужна git-верификация (seal-commit раньше соседей);
  пока deterministic-флаг + TODO на git-order-check.
- Кворум дороже (N запусков) — цена за незахватываемость.

# 7. Инварианты
- **OQ-1** Нет семантического вердикта от 1 судьи — кворум N независимых (разные model/lens).
- **OQ-2** Рассогласие судей → contested (детекция захвата), не молчаливое решение.
- **OQ-3** Независимость по проверяемому провенансу (seal-порядок) > захватываемая поверхность.
- **OQ-4** Оракул СМЯГЧЁН, не устранён — остаточная LLM-зависимость заявлена, не спрятана.
