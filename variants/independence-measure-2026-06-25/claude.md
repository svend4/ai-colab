# 0. Визитка
> Котёл-сверка показала: «по смыслу, не количеству» реально лишь настолько, насколько мы **измеряем
> независимость**, а не объявляем её. seal_hash доказывает ПОРЯДОК (писал до чтения), но не то, что
> два варианта — не клоны одной модели. Здесь: мера, превращающая «5 вариантов» в «сколько РАЗНЫХ
> свидетелей на самом деле» (effective witnesses). N клонов = 1 свидетель.

# 1. Условия применимости
Применять при сведе́нии вариантов, когда совпадение хотят трактовать как улику (И-4). НЕ применять к
механике (один источник истины). Бесполезно, если у вариантов нет метаданных генотипа (модель/линза/seed).

# 2. Что такое (не)независимость — источники сцепления
1. **Порядок/контаминация** — один читал другого. (Ловит seal_hash/seal_time — уже есть, `ripeness_gate`.)
2. **Генотип** — та же модель+seed+промпт → коррелируют БЕЗ чтения друг друга. (seal НЕ ловит.)
3. **Линза/метод** — тот же подход → коррелируют.
4. **Общий вход** — оба читали один источник → коррелируют через него.

# 3. Дизайн — «эффективное число свидетелей»
Аналог effective sample size из статистики: 5 вариантов, но если 3 — почти-клоны, эффективно ~3.

- **3.1. Генотип-вектор** каждого варианта из front-matter: `(model, lens/author, seed)`.
- **3.2. Поверхностная дивергенция** тел: `1 − Jaccard(токены A, токены B)`. ВЫСОКАЯ = тексты разные
  (хорошо: меньше шанс копирования / общий словарь). НИЗКАЯ при разном смысле — подозрительно (эхо).
  *(Это операционализирует тест котла «разные словари = подлинное схождение» = мой P-2.)*
- **3.3. Парная похожесть** `sim(A,B)` = смесь: одинаковый генотип (model==,lens==,seed==) ↑ + низкая
  поверхностная дивергенция ↑. Высокая sim = клоны.
- **3.4. Кластеризация по похожести** (порог): почти-клоны схлопываются в один кластер-свидетель.
- **3.5. Effective witnesses** = число кластеров. Сила claim = сколько РАЗНЫХ кластеров его поддержали,
  НЕ сырой count. Прямо реализует «N клонов = 1 свидетель» и «вес = разнообразие, не число».

# 4. Уникальный вклад
- **Effective witnesses через кластеризацию клонов** — детерминированно (без LLM!), объяснимо, заменяет
  `count` на `diversity-weighted count`. Это и есть машинная форма «по смыслу, не количеству».
- Разделение стен: эта мера НЕ требует канонизации claim-по-смыслу (несущая стена №1, LLM-зависимая) —
  работает на генотипе + поверхности. Две стены строятся НЕЗАВИСИМО.
- Поверхностная дивергенция как СИГНАЛ независимости (низкий surface-overlap при смысловом согласии =
  золото; высокий overlap = подозрение на копию). Инвертирует наивное «похожий текст = согласие».

# 5. Evidence / обоснование
Котёл-сверка дала это требование явно (несущая стена №2: «независимость измерить, не объявить»).
Effective sample size — устоявшийся приём; перенос на варианты прямой. immune.py уже имеет прообраз
(«измеритель независимости генотипов» упомянут линзой эволюции) — будет партнёром сверки.

# 6. Риски
- Генотип-метаданных может не быть → деградация к поверхностной мере (флажить, не падать).
- Порог кластеризации произволен → вынести как параметр + дефолт из дизайна, не магия.
- Поверхностный Jaccard груб (синонимы) — но для ОБНАРУЖЕНИЯ копий (не для смысла) достаточно.

# 7. Открытые вопросы
