# 0. Визитка
> `view` = именованный РЕЛЕВАНТНЫЙ СРЕЗ существующего канона под задачу/казус/агента, собранный обходом
> НАШИХ рёбер (`related:` + `[[ссылки]]`), а НЕ новый формат. Агенту подаётся рабочее множество, не весь
> репо. Режимы frozen (инлайн тела — самодостаточный срез) / live (только пути — дёшево). Budget-aware.

# 1. Условия применимости
Когда агенту/человеку нужен релевантный контекст под конкретную задачу, а не весь репозиторий. НЕ для
механики (один источник истины). Работает только если канон уже связан рёбрами (related/[[links]]).

# 2. Проблема
Агент либо тонет (весь репо в окно = дорого, размывает внимание), либо читает наугад (теряет связанное).
Нужна ПОДАЧА: от seed-файла собрать связный подграф релевантного и отдать как срез. У нас есть граф
(`edges.py`, `[[links]]`, `portals`), но «подачи среза агенту» — нет.

# 3. Дизайн (над СУЩЕСТВУЮЩИМ каноном, без нового формата)
- **3.1. Срез = обход графа.** seed (id/файл) → транзитивное замыкание по `related:` + `[[ссылки]]` до
  глубины N → связный подграф id-шников. Переиспользует наши рёбра (композиция, не новый граф).
- **3.2. Режимы.** `--frozen` (инлайн тела файлов — самодостаточный «скриншот» среза, переживёт правки),
  `--live` (только пути+визитки — дёшево, разворот по требованию).
- **3.3. Budget-aware.** `--budget N` (≈ символы/4): тянуть блоки по близости (depth, потом тип-приоритет),
  пока бюджет не исчерпан → «контекст как рабочее множество, не свалка».
- **3.4. Именованный срез.** `--name X` → сохранить как `views/<X>.md` (список id + режим + дата) —
  пересылаемый артефакт. Без `--name` — вывод в stdout.

# 4. Уникальный вклад
- **Над существующим каноном, без нового формата/адреса** — срез = обход НАШЕГО edge-графа, не порт Q6.
- **frozen/live + budget** — подача контекста агенту как рабочее множество (наш `portals`/`consensus`
  отвечают «где кластеры», `view` отвечает «что подать в окно под ЭТУ задачу»).
- **Срез всегда расширяем** — `--depth+1` достаёт больше; ничего не «спрятано» (плоский канон под ним).

# 5. Evidence
У нас есть `edges.py` (типизированные рёбра + transitive), `portals.py` (кластеры), `[[links]]`,
front-matter `related:`. View — недостающее звено «подача среза», над всем этим.

# 6. Риски
- Срез глубины N может ПОТЕРЯТЬ нагруженный факт вне замыкания (ровно находка `.inf` accuracy-harness:
  «reference сохраняет корректность ⟺ граф достаёт каждый нагруженный факт») → флажить охват, `--depth`
  расширяем, fallback к полному.
- Budget-приоритет (что тянуть первым) — эвристика; не оракул. Помечать, чем ранжировано.

# 7. Инварианты
- **V-1** Над существующим каноном (никакого нового формата/Q6).
- **V-2** frozen (копия) / live (ссылки) — два явных режима.
- **V-3** Budget-aware подача (окно = рабочее множество).
- **V-4** Срез всегда расширяем (не теряет — можно до-раскрыть до полного).
