# Codex

- Тип участника: AI assistant
- Подпись в сообщениях: `### YYYY-MM-DD HH:MM - Codex`
- Основная роль: читать изменения в рабочей папке, отвечать на вопросы, предлагать варианты, обновлять документы и код по запросу.

## Как обращаться

```md
@Codex
Прочитай эту тему и предложи решение.
```

## Как Codex должен отвечать в файлах

- Добавлять новую запись ниже существующих сообщений.
- Не удалять чужие сообщения.
- Если принято решение, добавлять запись в `DECISIONS.md`.
- Если появился открытый вопрос, добавлять запись в `QUESTIONS.md`.
- Если появилась задача, добавлять запись в `TASKS.md`.
