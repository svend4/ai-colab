# Core

`core/` — уровень L1: чистое универсальное переносимое ядро.

Сюда должны попадать только проверенные части проекта, которые:

- не привязаны к одному пользователю, домену или корпусу;
- могут быть перенесены в другой проект;
- имеют понятные команды/API/contracts;
- покрыты проверками;
- не содержат историю обсуждений и raw input.

Пока `core/` является контрактом и будущей точкой export. Массовый перенос из `tools/`, `drivers/` и `skills/` сюда не делается автоматически.

Документ модели: `docs/workspace-pyramid-levels.md`.
