# Sandbox reports

Очищенные summaries по внешним источникам и sandbox experiments.

Сырые логи остаются в `sandbox/runs/`. В report переносится только то, что безопасно читать людям и агентам:

- цель проверки;
- источник;
- метод;
- результаты;
- риски;
- что можно перенести в main project;
- какие вопросы остались.

Важные отчёты можно копировать или переносить в общий `reports/` и связывать с `tasks/`, `questions/`, `decisions/`.
