# Question alchemy: calcination -> dissolution -> coagulation

## Источник метафоры

Алхимическая последовательность используется не как мистика, а как форма информационной обработки.

## Технический принцип

```text
calcination  = сжечь лишнюю форму, оставить сырой вопрос
dissolution  = растворить вопрос в источниках и вариантах
separation   = отделить consensus от divergence
conjunction  = соединить consensus в рабочую модель
coagulation  = превратить модель в task/tool/doc/decision
```

## Что можно проверить

- [ ] Взять один `open` вопрос из `question_tree.py`.
- [ ] Разложить его по пяти стадиям.
- [ ] Проверить, получается ли более ясный next action.
