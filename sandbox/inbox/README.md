# Sandbox inbox

Сюда попадает первичное описание внешнего источника.

Не кладите сюда большие архивы или клоны, если они могут попасть в Git. Для источника сначала создаётся manifest по шаблону:

```text
sandbox/templates/external-source-manifest.template.json
```

Manifest должен отвечать:

- что это за источник;
- откуда он взят;
- кто разрешил его использовать;
- есть ли license/usage ограничения;
- есть ли риск секретов или персональных данных;
- какая цель анализа;
- ожидается только read-only или источник когда-нибудь может стать execute candidate.
