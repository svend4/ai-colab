# T-263 - Cross-agent commit coordination and synthesis gate

## Цель

Подготовить репозиторий к будущему безопасному commit после большой параллельной работы нескольких агентов и тем. Нужно не коммитить всё вслепую, а разделить изменения на группы: готовое к фиксации, требующее synthesis/human review, runtime-шум, чужая half-done работа.

## Работы

- Снять текущий `git status`, pipeline, stream-check, generated-check.
- Сопоставить новые задачи/отчёты/потоки T-244..T-262 и работы других агентов.
- Сформировать commit-readiness report для людей и агентов.
- Выделить batch-кандидаты для будущих commit и файлы, которые нельзя смешивать.
- Зафиксировать открытые вопросы для consensus/divergence.
- Не делать commit в этой задаче без отдельного подтверждения человека.

## Safety

- Не удалять чужую работу.
- Не переводить `proposed` в `accepted` без человека.
- Не включать runtime/log noise в будущий commit без отдельной причины.
- Не скрывать divergence; вынести спорное в отдельные секции отчёта.
