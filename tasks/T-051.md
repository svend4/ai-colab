# T-051 — runtime acceptance for repo-runner MCP

Цель: после восстановления runtime проверить, что `T-049` и `T-050` работают вместе.

Минимальные проверки:

```powershell
python drivers\repo-runner\test_inventory.py
python tools\validate.py
python tools\generate.py --check
```

MCP-проверки:

- initialize;
- tools/list возвращает 3 инструмента;
- call `repo_summary` на безопасной fixture-папке;
- запрет выхода за `REPO_RUNNER_BASE`;
- `max_files` приводит к `truncated: true`.

## Blocked 2026-06-21 - Codex

`repo-runner test_inventory.py` прошёл в Batch B, но оставшаяся часть задачи требует MCP stdio (`tools/list` и `repo_summary`).

После диагностики `T-081` известно, что текущая Windows/Python среда не может создать asyncio subprocess pipe:

```text
asyncio.windows_utils.pipe -> _winapi.CreateFile -> PermissionError [WinError 5]
```

Вывод: `T-051` не должна выдаваться агентам как ready, пока MCP stdio acceptance не будет запущена во внешней среде или через sync subprocess workaround.
