# Новый драйвер sqlite — read-only инспекция/запрос SQLite-БД (направление 2)

Направление 2 по запросу Stefan (новый драйвер под реальный источник): доступ к SQLite-базам
приложений. Дополняет `data` (CSV) реальным источником данных. Новая папка `drivers/sqlite/` —
нулевая коллизия.

Реализовано по схеме драйвера:
- `drivers/sqlite/sqlite_driver.py` — engine: `list_tables/table_schema/table_head/query`;
  **read-only на уровне СУБД** (`mode=ro` URI — запись/DDL невозможны), confinement, whitelist
  суффиксов, валидация имени таблицы (нет инъекции), `query` — только одиночный SELECT/WITH,
  лимит строк, redaction секретов в ячейках;
- `drivers/sqlite/mcp_server.py` — FastMCP stdio + audit (4 инструмента, risk=medium);
- `drivers/sqlite/test_sqlite.py` — тест: tables/schema/head+redaction, SELECT-guard,
  mode=ro блокирует запись, confinement, суффикс — зелёный;
- `drivers/sqlite.md` — манифест с `tools:` (валидатор: `drivers tools: 7`).

Каталог: 9 драйверов; `validate OK=9/0/0`. `status: draft` по D-015 (верифицировал 1 агент).
