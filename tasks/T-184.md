# T-184: Внедрение Markdown Streams

> Рождено из консенсуса по теме `commit-policy` (Сверху).

## Задача (White Path / Code)
Реализовать механизм, при котором агенты вместо создания отдельных тяжелых Git Worktrees (Level 1) могут фиксировать свои промежуточные "сырые" мысли в `streams/`. 
Скрипт `synthesis_helper.py` уже обновлен, но нужно задокументировать это как официальную политику и, возможно, доработать `top.py` или pipeline для автоматического управления стримами.

## Критерии приемки
- [ ] Написана финальная политика в `docs/commit-stream-policy.md`.
- [ ] Описаны правила для агентов: как создавать stream.
- [ ] Задача ратифицирована.
