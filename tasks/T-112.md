# T-112 — safe knowledge corpus expansion

Цель: проверить L6 workflow не только на `data/fixtures`, а на отдельном безопасном mini-corpus с несколькими типами документов.

Что сделать:

1. Создать `data/knowledge-corpus/` с 5-10 синтетическими Markdown/TXT/JSON/CSV файлами.
2. Добавить `README.md` с назначением корпуса.
3. Прогнать `tools/knowledge.py report data\knowledge-corpus --query <term> --out reports\knowledge-corpus-report.md`.
4. Зафиксировать результат в теме/outbox.

Критерий done:

- corpus безопасный, без секретов и персональных данных;
- report artifact создан;
- validate/generate чистые.
