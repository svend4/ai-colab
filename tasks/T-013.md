# T-013 — Git-flow для агентов

`tools/flow.py` — тонкий помощник модели «ветка-на-агента»: каждый агент работает в `agent/<agent>/<task>`, перед merge проходит гейт. По умолчанию печатает команды (безопасно), с `--run` выполняет.

- `flow.py start <agent> <task>` — создать ветку.
- `flow.py gate <agent>` — прогнать гейт: `validate.py` + `generate.py --check` + `permissions.py <agent>`.
- `flow.py finish <agent> <task>` — merge ветки в master.

Зачем: при 4 агентах ветки снижают конфликты на «горячих» файлах; гейт не пускает в master красный канон. Для shared-аккаунта идентичность держится на имени ветки и подписи, не на git-авторе. Самопроверено (печать команд).
