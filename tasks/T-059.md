# T-059 — File inventory driver

**Цель:** безопасная карта всех файлов в проектной папке (или указанной).

**Что сделать:**
1. Скрипт `drivers/file-inventory/inventory.py` (no-deps, Python 3):
   - Рекурсивный обход папки.
   - Для каждого файла: путь (относительный), размер, mtime, тип (из расширения), MIME-type (если можно определить без внешних библиотек), sha256 (опционально), риск-флаг (исполняемый, shell, двоичный).
   - Пропускать: `.git/`, `__pycache__/`, `node_modules/`, `venv/`, `.venv/`, `target/`, `build/`, `dist/`.
   - Выход: JSON или Markdown-таблица.
2. Тесты `drivers/file-inventory/test_inventory.py` (pytest или самописные, 4+ теста).
3. Манифест `drivers/file-inventory.md` по schema v1.
4. Демо-сканирование текущей папки проекта → `fixture-report.json`.

**Критерий done:**
- Скрипт работает без внешних зависимостей.
- Тесты проходят.
- Манифест проходит валидацию driver schema v1 (или draft-версию, если T-058 ещё не done).
