2. Тесты `drivers/file-inventory/test_inventory.py` (pytest или самописные, 4+ теста).
3. Манифест `drivers/file-inventory.md` по schema v1.
4. Демо-сканирование текущей папки проекта → `fixture-report.json`.

**Критерий done:**
- Скрипт работает без внешних зависимостей.
- Тесты проходят.
- Манифест проходит валидацию driver schema v1 (или draft-версию, если T-058 ещё не done).
