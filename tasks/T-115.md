# L6 FTS5 — ранжированный полнотекстовый поиск (направление 3)

Углубление L6 (направление 3 по запросу Stefan): поверх knowledge workflow добавлен
полнотекстовый поиск SQLite **FTS5** с ранжированием **bm25** (без внешних зависимостей).

Сделано в `tools/knowledge.py`:
- `_build_fts(conn)` — строит виртуальную таблицу `kn_fts(doc_id, path, summary)` из documents
  (вызывается в `build`); возвращает False и откатывается на LIKE, если sqlite без FTS5;
- `fts_search(conn, query, limit)` — `MATCH` + `bm25` ранжирование, запрос оборачивается в FTS5-фразу
  (пунктуация не ломает синтаксис); fallback на `wb.query_documents` (LIKE);
- команда `search <db> <текст>` (ранжировано) рядом с `query` (LIKE); `report` использует FTS для
  секции запроса.

Проверка: `report --query`/`search` дают ранжированные результаты; тест `tools/test_knowledge.py`
расширен проверкой FTS — зелёный. Vector/RAG по-прежнему отложены до спроса (D-010).
