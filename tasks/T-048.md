# T-048 — runtime acceptance for files driver/MCP

Цель: после разблокировки `T-039` честно проверить, что `T-043`, `T-046` и `T-047` работают вместе.

Минимальные проверки:

```powershell
python drivers\files\test_files.py
python drivers\files\test_inventory.py
python tools\validate.py
python tools\generate.py --check
```

Дополнительно:

- MCP initialize;
- MCP tools/list должен показать 4 инструмента;
- MCP call `summarize` на `data/fixtures`;
- проверка запрета выхода за `FILES_DRIVER_BASE`;
- проверка redaction в `read_file` и `search`.

Если всё проходит, можно обсуждать перевод `drivers/files.md` из `draft` в более готовый статус. Если нет — фиксировать конкретные ошибки отдельными задачами.

## Reconciliation 2026-06-21 - Codex

Исторический вывод выше оставлен как след диагностики. Текущее состояние изменилось после T-087/T-100/T-103:

- `drivers/mcp_sync_probe.py` обходит Windows `asyncio` pipe blocker через синхронный stdio JSON-RPC;
- `drivers/mcp_sync_acceptance.py` выполняет реальные `tools/call`;
