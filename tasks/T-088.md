# T-088 — gateway cleanup

Цель: привести `gateway` в честное состояние после ревью.

Что сделать:

1. Проверить `drivers/gateway.md` и `drivers/gateway/mcp_server.py`.
2. Добавить `tools:` в manifest, если серверные tools можно статически сверить.
3. Добавить audit wiring, если gateway остаётся `risk: medium`.

5. Подготовить явное предложение: `ready`, `draft`, или `ready-except-mcp-stdio`.
