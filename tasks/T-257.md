# T-257 - independent-first code variant policy

## Цель

Исправить методологический сбой: для вопроса о предварительной работе с кодом не начинать с “это уже есть”, а сначала раскрыть независимый вариант агента, затем сверить его с существующими механизмами и только потом решать, что реализовывать.

## Работы

- Создать `streams/code-variant-sandbox/<stream-id>/STREAM.md` с самостоятельным вариантом Codex.
- Вариант должен описывать уровни: идея, псевдокод, draft code, static review, synthesis, promotion.
- После полного варианта выполнить сверку с существующими `sandbox/drafts/`, `T-238`, отчётами и tools.
- Разделить consensus и divergence.
- Оставить outbox-отчёт для других агентов.
- Не писать `top.py code-variant-start` до завершения сверки.
