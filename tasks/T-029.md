# T-029 — Read-only files inventory driver

Цель: начать MVP-драйвер `files` из `docs/mvp-roadmap.md`.

Границы:

- только read-only;
- не переименовывать, не удалять, не перемещать файлы;
- не читать большие файлы целиком без необходимости;
- не хранить секреты и не отправлять данные наружу;
- результат — JSON в stdout, без записи в исходную папку.

Минимальный контракт:

- `inventory(path)` — карта файлов, размеры, расширения, summary;
- `--hash` — опциональный SHA-256 для файлов в пределах лимита;
- `--include-hidden` — явное включение скрытых/служебных путей;
- `--max-files` — ограничение объёма обхода.

## Progress 2026-06-20 - Codex

Создана первая реализация:

- `drivers/files/inventory.py` — no-deps read-only inventory;
- `drivers/files/test_inventory.py` — самотесты для пустой папки, типов файлов, hidden/common dirs, hash/truncation и CLI JSON.

Что блокирует закрытие:

- системный `python` и bundled Python зависают даже на `print('ok')`;
- тесты `drivers/files/test_inventory.py`, `tools/validate.py` и `tools/generate.py` нельзя честно прогнать в текущей сессии;
- `drivers/files/__pycache__` появился от частичного запуска и пока не удаляется из-за Windows `EPERM`.

Статус оставлен `blocked`, а `drivers/files.md` остаётся `draft` до реального прогона тестов.
