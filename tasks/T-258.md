# T-258 - independent-first guard for variant-start ordering

## Цель

Исправить верхний инструментальный процесс так, чтобы команда запуска варианта не подталкивала агента к чтению существующих документов или repo-search до записи самостоятельного варианта.

## Контекст

Пользователь справедливо указал, что новая политика не должна оставаться только текстом. Если агент сначала ищет готовые механизмы, а уже потом пишет своё мнение, он теряет независимый потенциал варианта. Поэтому для задач типа “разработать свой вариант, затем сверить” нужен guard на уровне команд верхнего слоя.

## Работы

- Создать independent stream по теме `variant-start-order-policy` до чтения `tools/top.py`.
- После записи independent stream сравнить вариант с текущим `variant-start`.
- Если текущий порядок нарушает independent-first, изменить `tools/top.py` так, чтобы repo-search не выполнялся раньше stream-старта и первичного варианта.
- Обновить тесты и документацию.
- Оставить outbox-отчёт для людей и агентов.
