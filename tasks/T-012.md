# T-012 — Роли и path-права

`tools/permissions.py <agent>` сверяет изменённые файлы (git diff vs HEAD + новые, либо переданные аргументами) с разрешёнными путями агента из `tools/permissions.json`. Глоб: `**`, `dir/**`, `*.md`, точный путь.

Политика-демо: `claude`/`codex` — `**` (maintainer); `mavis` — work-зоны (`tasks/queues/темы/...` + `STATUS.md`/`dialog.md`), без `PROTOCOL.md`/`tools/` (worker). Это **совещательный** guard: агент объявляет себя сам, поэтому ловит ошибки, а не злонамеренность. В hook не встроен (shared-аккаунт не даёт атрибуции); запускается агентом вручную или через `flow.py gate`.

Самопроверено: in-zone → OK; out-of-zone → exit 1; неизвестный агент → ERROR.
