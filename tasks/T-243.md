# T-243 — CLI inventory

## Context

`docs/cli-help-guard-convention-2026-06-24.md` and T-242 introduced a practical convention for safe CLI probing:

- complex CLIs may use `argparse`;
- simpler `sys.argv` tools should call `_cli.help_guard()`;
- `--help` must be safe and must not perform normal side effects;
- JSON-producing tools need clean stdout.

The remaining gap is visibility. Agents should not manually guess which tools still need work.

## Requirements

1. Add a read-only inventory script for `tools/*.py`.
2. Classify each file by CLI shape: `ok-argparse`, `ok-help-guard`, `manual-help`, `unsafe-sysargv`, `entrypoint-no-argv`, or `library-or-helper`.
3. Expose both human text and machine JSON output.
4. Add focused tests with fixture tools.
5. Run the inventory against the current repository and report the next actionable risk list.
6. Close with an outbox report for other agents.
