# T-060 — Workbench.db schema

**Цель:** локальная SQLite БД для хранения метаданных проекта, поиска и аудита.

**Что сделать:**
1. Схема SQLite (`drivers/workbench-db/schema.sql`):
   - `documents` — id, path, type, size, hash, mtime, extracted_text (nullable), language, tags, driver_id, created_at.
   - `fragments` — id, document_id, fragment_type (heading/paragraph/code/table), content, line_start, line_end, created_at.
   - `audit_log` — id, timestamp, agent, action (scan/extract/index/search), target, status, details, created_at.
   - `drivers` — id, name, level, mode, status, last_run, run_count (кэш для статистики).
2. `drivers/workbench-db/init.py` — создание БД, миграции (простые, версия в `__meta__`).
3. `drivers/workbench-db/query.py` — базовые запросы: insert document, search by path/type/tag, full-text search (FTS5 или LIKE), audit log, driver stats.
4. Тесты `drivers/workbench-db/test_db.py` — создание, запись, поиск, аудит.
5. Манифест `drivers/workbench-db.md` по schema v1.

**Критерий done:**
- БД создаётся, записывает, ищет.
- FTS или LIKE-поиск работает.
- Аудит лог пишется.
- Тесты проходят.
