# T-163 — Expose conveyor supervisor in top command panel

## Цель

Сделать runtime-надзиратель `tools/conveyor.py` доступным через верхний слой `tools/top.py`, чтобы человек и агент видели состояние workflow-конвейера одной стандартной командой.

## Done criteria

- `python tools/top.py conveyor [--target N] [--idle M] [--json]` вызывает `tools/conveyor.py status`.
- В `top.py buttons` есть сценарий `conveyor-status`.
- `tools/test_top.py` покрывает parser/button для `conveyor`.
- `tools/capabilities.py`, `tools/README.md` и `docs/top-layer-command-groups.md` упоминают новую top-команду.
