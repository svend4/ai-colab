# T-081 — MCP stdio subprocess / Windows pipe blocker

Цель: разблокировать MCP acceptance-задачи, которые требуют запуска MCP server по stdio.

Наблюдение:

- `drivers/files/test_files.py` проходит;
- `drivers/files/test_inventory.py` проходит;
- `drivers/mcp_acceptance_test.py files` не может поднять server;
- `drivers/mcp_handshake_test.py` теперь падает в том же слое;
- traceback указывает на `asyncio.windows_utils.pipe -> _winapi.CreateFile -> PermissionError [WinError 5]`.

Что проверить:

1. Plain subprocess pipe:

   ```powershell
   python -c "import subprocess, sys; p=subprocess.Popen([sys.executable,'-c','print(123)'], stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True); print(p.communicate())"
   ```

2. Asyncio subprocess pipe:

   ```powershell
   python -c "import asyncio, sys; async def main(): p=await asyncio.create_subprocess_exec(sys.executable,'-c','print(123)',stdout=asyncio.subprocess.PIPE,stderr=asyncio.subprocess.PIPE); print(await p.communicate()); asyncio.run(main())"
   ```

3. MCP stdio with one small server after UTF-8 console setup.

Критерий done:

- либо MCP stdio handshake/acceptance снова проходит;
- либо создан отдельный documented runtime blocker с точной причиной и обходным путём.

## Result 2026-06-21 - Codex

Диагностика:

- plain `subprocess.Popen(..., stdout=PIPE, stderr=PIPE)` работает;
- `asyncio.create_subprocess_exec(..., stdout=PIPE, stderr=PIPE)` падает на `asyncio.windows_utils.pipe -> _winapi.CreateFile -> PermissionError [WinError 5]`;
- `asyncio.WindowsSelectorEventLoopPolicy()` не помогает: `NotImplementedError`;
- MCP Python stdio client использует failing asyncio subprocess path.

Вывод: это runtime/permissions blocker текущей Windows/Python среды, а не ошибка `files` driver.

Документация: `docs/mcp-stdio-windows-pipe-diagnostics-2026-06-21.md`.

Обходы:

- запускать MCP acceptance во внешней среде, где `asyncio.create_subprocess_exec` с pipe работает;
- или написать отдельный sync subprocess MCP smoke client на `subprocess.Popen`;
- пока продолжать non-MCP задачи.
