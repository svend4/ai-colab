# Задача T-237

## Контекст
При глобальном Dogfooding-эксперименте мы загрузили `indexes/` в песочницу. Оказалось, что у нас нет инструмента для проверки "битых" ссылок во внешних Markdown-документах до их слияния с основным проектом.

## Требования
1. Создать read-only утилиту `tools/sandbox_link_checker.py`.
2. Сканировать все `.md` файлы в изолированной директории.
3. Проверять относительные ссылки на другие файлы.
4. Формировать отчет с перечнем неработающих (битых) ссылок.
