# T-067 — pipeline placeholder gating

Сделано:

- `ready_sorted()` пропускает placeholder-задачи;
- `build_pipeline_state()` показывает их как `placeholder task`;
- создана документация `docs/pipeline-placeholder-gating.md`.

Почему статус `blocked`: Python/runtime остаётся заблокированным `T-039`, поэтому runtime-приёмка `tools/pipeline.py status/snapshot/next` не запускалась.
