# T-067 — pipeline placeholder gating

Цель: не позволять `tools/pipeline.py next <agent>` автоматически выдавать резервные placeholder-задачи вида `(зарезервировано — заполните)`.

Сделано:

- добавлен `is_placeholder_task(t)` в `tools/pipeline.py`;
- `ready_sorted()` пропускает placeholder-задачи;
- `build_pipeline_state()` показывает их как `placeholder task`;
- создана документация `docs/pipeline-placeholder-gating.md`.

## Result 2026-06-21

Пользователь прислал `queues/inbox/documentoutput.md` с результатом Batch C:

```text
===== pipeline ready_sorted no-write =====
[]
```

Вывод: placeholder-задачи не выдаются агентам через `ready_sorted()`. Задача закрыта.
