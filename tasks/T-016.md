# T-016 — Метрики канона

`tools/metrics.py` читает front-matter и выдаёт сводку одним взглядом: задачи (всего, по статусам, готовы/заблокированы по DAG), вопросы, решения, темы — по статусам, и состояние очереди (`inbox`/`claimed`/`done`/`failed`). Флаг `--json` — машинный вывод (для дашборда/мониторинга).

Самопроверено: корректные счётчики и ready/blocked на фикстуре.
