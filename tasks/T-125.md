# T-125 — system capabilities manifest

Консенсусный пункт: людям нужны читаемые docs, но агентам нужна короткая машинная карта текущих возможностей.

Что сделать:

1. Спроектировать `system-capabilities.json` или `logs/system-capabilities.json` без секретов.
2. Включить слои, драйверы, команды, safety-границы, maturity/status и ссылки на docs.
3. Добавить генератор `tools/capabilities.py snapshot` или использовать минимальный no-deps Python script.
4. Добавить Markdown-снимок, если это помогает людям.
5. Подключить проверку к `validate.py` только после стабилизации формата.

Критерий done: новый агент может прочитать один JSON и понять, какие действия разрешены и где документация.
