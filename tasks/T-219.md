# T-219: Усиление маскировки секретов

> Рождено из консенсуса по теме `driver-acceptance-batch` (Сверху).

## Задача (White Path / Code)
Батч-тесты показали 19/19 успешных запусков, но замечена уязвимость: маскировка (`redaction`) скрывает только базовые паттерны `api_key|token|secret`. Возможны утечки абсолютных путей хоста.

Нужно написать код в `files_driver.py` (или `core/`), который:
1. Заменяет абсолютные пути хоста (например `C:/Users/stefan/`) на относительные переменные `$WORKSPACE`.
2. Расширяет словарь redaction.

## Критерии приемки
- [ ] Абсолютные пути фильтруются в ответах инструментов.
- [ ] Добавлены тесты на redaction.
