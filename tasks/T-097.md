# Demo среднего слоя — `tools/demo_bridge.py`

Продуктовая демонстрация (не правка ревью): один запуск показывает, что AI-агент получает
от верифицированных read-only драйверов на реальной локальной папке — то, что `gateway`
отдаёт за одним MCP-разъёмом, но вызвано напрямую (быстро, без stdio → работает и там, где
async MCP падает WinError 5).

Показывает 4 способности на `data/fixtures`:
1. `files.summarize` — карта папки (файлы, байты, расширения);
2. `files.search` — поиск с маскировкой секретов в выдаче;
3. `repo-runner.inspect` — языки/тесты/риски (код не запускается);
4. `workbench.memory` — занести документы и найти по запросу.

Запуск: `python tools/demo_bridge.py [папка]` (по умолчанию `data/fixtures`). Прогон: `exit 0`,
вывод — связный «AI-OS Bridge — демо среднего слоя». svend4 (запуск чужого кода) явно вынесен
в отдельный слой + песочница.
