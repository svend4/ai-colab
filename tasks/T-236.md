# Задача T-236

## Контекст
В ходе глобального эксперимента Dogfooding мы попытались проанализировать директорию `drivers/` в песочнице. Выяснилось, что наши инструменты не умеют автоматически валидировать `manifest.json` и другие JSON-структуры внешнего кода на соответствие нашим стандартам.

## Требования
1. Создать read-only инструмент `tools/sandbox_schema_validator.py`.
2. Инструмент должен находить все `.json` файлы во входящей папке песочницы.
3. Если файл называется `manifest.json`, проверять его по базовой схеме драйвера.
4. Выдавать отчет о структурных ошибках без запуска внешнего кода.
