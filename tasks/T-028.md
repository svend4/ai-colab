# T-028 — Добровольный heartbeat/live-room

Задача по Q-012/D-012: добавить live-слой без превращения его в обязательную дисциплину для каждого агента.

Реализовано:

```bash
python tools/pipeline.py heartbeat codex T-028 --progress 80 --note "работаю" --eta "10m"
```

Что создаётся:

- `logs/heartbeat/<agent>.json` — отдельный файл агента, чтобы не было горячего общего файла записи.
- `logs/heartbeat.json` — агрегированный машинный снимок.
- `LIVE.md` — человекочитаемая live-комната.

Границы:

- Heartbeat добровольный.
- `fresh` = обновление младше 15 минут; старее считается `stale`.
- Обязательный heartbeat можно обсуждать позже, если будет 3+ одновременно работающих агента или длинные задачи с ETA.
