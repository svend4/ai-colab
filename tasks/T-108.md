# L6 knowledge workflow — `tools/knowledge.py`

Следующий пункт roadmap `layers-coverage.md` после L2-acceptance: практический сценарий
`ingest → query → report` на безопасном локальном корпусе (без vector/RAG до спроса, по D-010).

Сделано: `tools/knowledge.py` поверх готовых движков (`files`, `workbench.db`):
- `report <корпус> [--db] [--query]` — сканирует корпус драйвером `files` (summary = первая
  строка, **redacted**), заносит в L6-память, считает состав по типам/рискам, отвечает на запрос,
  печатает markdown-отчёт; база персистентна и переспрашивается;
- `query <db> <текст>` — запрос к сохранённой базе знаний.

Прогон: `python tools/knowledge.py report data/fixtures --query sample` → 8 документов,
состав по типам/рискам, 4 совпадения. Тест `tools/test_knowledge.py` зелёный (ingest/типы/
**redaction секрета в summary**/запрос). Запускается из `tools/` безопасно (не импортирует stdlib `queue`).
БД знаний — в `.gitignore` (runtime-артефакт).
