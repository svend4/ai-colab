# T-239 — Conveyor recover advisory

## Context

The multi-agent conveyor hit repeated reset and UI-indicator mismatch cases: agents disappeared from the visible UI while durable outbox reports and conveyor states remained usable. The completed agent-cell synthesis recommended making conveyor recovery the next build step before adding more sandbox orchestration.

## Requirements

1. Add a read-only `recover` command to `tools/conveyor.py`.
2. Detect common recovery situations: landed without output, landed output path missing, stale heartbeat, refill deficit, and unreferenced outbox reports.
3. Print concrete suggested commands without mutating the conveyor ledger.
4. Add tests in `tools/test_conveyor.py`.
5. Document the result in an outbox report.
