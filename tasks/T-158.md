# T-158 — Pipeline warns when service tasks finish without applied evidence

Контекст: T-156 добавил `--applied`, а T-157 научил verifier принимать pipeline done-маркеры. Следующий безопасный шаг — не блокировать агентов, но делать отсутствие evidence видимым в рабочем цикле, когда закрывается служебная задача по документации, инструментам, решениям или governance-процессу.

Критерии done:

- `pipeline.py done` остаётся backward-compatible без `--applied`;
- для служебных задач без `--applied` печатается `WARN`, но задача всё равно закрывается;
- обычные задачи без признаков service/governance не получают лишний warning;
- тест pipeline fencing покрывает warning и совместимость;
- документация объясняет мягкий режим: warning сейчас, возможный strict gate позже;
- `test_pipeline_fencing.py` и `top.py health` зелёные.
