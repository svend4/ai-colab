# Workflow backlog rescan tool

## Context
Файл перспективного бэклога (`темы/perspective-backlog-YYYY-MM-DD.md`) пока обновляется вручную, что приводит к задержкам и неточностям, когда задачи выполняются, но файл не обновляется.

## Goal
Создать сканер/утилиту (например `tools/backlog_rescan.py`), который сверяет backlog с выполненными задачами (tasks done), результатами assurance, выполненными workflow и списками TODO в документации, а затем предлагает patch (diff) для обновления списка кандидатов дозалива.

## Checklist
- [ ] Написать скрипт для парсинга текущего перспективного бэклога и извлечения списка кандидатов.
- [ ] Интегрировать проверку выполненных задач через `pipeline.py status` или парсинг `tasks/*.md`.
- [ ] Формировать patch или автоматически обновлять маркдаун файл (перемещая выполненные задачи в раздел shipped/closed).
