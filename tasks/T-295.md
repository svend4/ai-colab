# T-295 — Cauldron materializer

## Цель

Сделать так, чтобы полезные ответы агентов не оставались мёртвым текстом. Инструмент должен брать отчёты/сообщения и оформлять их как варианты обсуждения: consensus-ready, divergence, open-question, implementation-candidate.

## Additive scope

- Добавить новый инструмент или режим без удаления старых отчётов.
- Добавить индекс/пример в `reports/` или `queues/outbox/`.
- Не принимать решения за человека: только `proposed` и материалы для синтеза.

## Критерии

- Есть понятный формат варианта.
- Один и тот же вопрос может иметь несколько независимых вариантов разных агентов.
- Повторы не стираются: повторяющиеся пункты становятся кандидатами в consensus, расхождения уходят в отдельный список.
