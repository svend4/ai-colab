# T-024 — Read-only repo inventory driver

Спроектировать первый безопасный драйвер для сценария Sven4/local repos. На первом этапе он не запускает код, а строит карту репозитория:

- структура папок;
- языки и package-файлы;
- наличие тестов;
- команды запуска, если они явно указаны;
- потенциальные риски;
- краткое summary для агента.

Запуск `test`/`run` в эту задачу не входит. Для непроверенного кода нужна отдельная песочница и отдельное решение.
