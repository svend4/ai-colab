# T-080 — data driver: redaction + байтовый лимит

Закрывает находку F ревью T-078: `data`-драйвер декларировал `risk: medium`/`audit: true`,
но отдавал сырые ячейки CSV (PII/секреты) без маскировки и без байтового лимита.

Сделано:

1. `drivers/redaction.py` — канонический redaction-хелпер (`SECRET_RE`/`AWS_KEY_RE`/`redact`),
   единый источник вместо копий по драйверам (находка L). Семантика идентична `files_driver`.
2. `drivers/data/data_driver.py` — `head()` маскирует значения ячеек через `redact()` и
   ограничивает вывод `max_output_bytes` (1 048 576, как в манифесте `data.md`).
3. `drivers/data/test_data.py` — добавлен тест: `AKIA…`-ключ и `token=…`-значение маскируются.

Прогон: `python drivers/data/test_data.py` → `TESTS OK`.

Остаётся (отдельными задачами): аудит-логирование в MCP-инструментах risk≥medium (находка E),
миграция `files_driver` на общий `redaction.py`, относительные пути в выводе (low).
