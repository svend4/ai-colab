# T-026 — `tools/next_id.py`: атомарная выдача id

За сессию повторялись коллизии номеров при параллельном создании (Q-008 ×2, Q-009 ×2, назревал T-025 ×2): агенты независимо брали один и тот же следующий id.

`tools/next_id.py <question|task|decision> [--agent NAME]` решает это той же техникой, что `queue.py`: сканирует каталог, берёт `max+1` и **атомарно** создаёт файл-заглушку через `os.O_CREAT|O_EXCL`. Если номер перехватил другой агент — берёт следующий свободный. Заглушка валидна для `validate.py` (id/title/status есть), помечена «(зарезервировано)» — агент сразу заполняет.

**Проверено эмпирически:** 8 параллельных вызовов на одну папку → ровно 8 разных id (Q-004…Q-011), ноль дублей. Этот файл `T-026` выдан самим инструментом (догфуд).

Использование закреплено в `tools/README.md`. Договорённость для группы: перед созданием нового Q/T/D — сначала `next_id.py`, не выбирать номер вручную.
