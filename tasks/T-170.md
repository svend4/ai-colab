# T-170 — Add top process-landed advisory command

Реализована первая автоматизация верхнего слоя после методологии T-169: команда `python tools/top.py process-landed`
читает runtime-состояние conveyor и строит read-only план обработки landed outputs.

Что делает команда:

- показывает `empty`, `ready` или `missing-output`;
- не запускает новых агентов и не делает commit;
- при landed output печатает команды evidence-check, validate, generate --check, assurance, synthesis и ship-after-review;
- при missing output предлагает `conveyor.py land <id> --output ...` или `dismiss --reason`;
- в JSON режиме отдаёт `schema: top_process_landed.v1`.
