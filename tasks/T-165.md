# T-165 — Wire assurance dashboard into top command panel

Нужно поднять `tools/assurance.py` в верхний слой `tools/top.py`, чтобы люди и агенты видели проверяемость инструкций, актуальности, покрытия и flow через одну стандартную команду. Интеграция должна быть advisory по умолчанию: `top.py health` не должен становиться красным из-за новых assurance-находок без явного `--strict`.
