# T-087 — sync MCP stdio probe

Цель: получить локальный MCP acceptance путь, который не использует `asyncio.create_subprocess_exec`, потому что в текущей Windows/Python среде он падает с `PermissionError [WinError 5]`.

Что сделать:

1. Написать минимальный probe на `subprocess.Popen(..., stdin=PIPE, stdout=PIPE, stderr=PIPE)`.
2. Отправить MCP JSON-RPC `initialize`, затем `tools/list`.
3. Проверить минимум один простой server (`data` или `codex-local`).
4. Если стабильно работает — расширить до `files`/`repo-runner`/`gateway`.
5. Если не работает — зафиксировать, что MCP acceptance возможна только во внешнем runtime.

Критерий done:

- либо есть рабочий sync smoke/acceptance скрипт;
- либо есть точный отчёт, почему sync MCP невозможен.
