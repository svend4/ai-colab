# T-200 — Коммит selective-add

**Цель:** зафиксировать изменения, не создавая хаоса в git.

**Проблема:** 145 строк git status — много изменений, нужен selective-add по D-019 (commit streams policy).

**Что сделать:**
1. Запустить `git status --short` — получить список изменённых файлов.
2. Разделить на группы:
   - Группа A: генератор/индексы (STATUS.md, board.md, TASKS.md, QUESTIONS.md, DECISIONS.md, index.json) — обновляются `generate.py`.
   - Группа B: новые инструменты/драйверы (adoption.py, blocks.py, friction.py, drift_check.py, top.py, commit_lock.py, инструменты Codex) — основные изменения.
   - Группа C: новые темы/документы (темы/*.md, docs/*.md) — продуктовые изменения.
   - Группа D: тесты и фикстуры (test_*.py, fixture-*).
3. Сделать коммит группами (не один большой коммит).
4. Для каждого коммита: `generate.py --check` → `validate.py` → `git add selective` → `git commit`.

**Критерий done:**
- Все 145 строк закоммичены.
- Канон зелёный после каждого коммита.
- Git status чистый.
