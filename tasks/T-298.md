# T-298 — Butterfly semantic hardening

## Цель

Завершить незакоммиченный пакет смыслового котла как самостоятельное,
проверяемое изменение:

- выбор атомов по стратегии `gap`;
- различение поддержки и противоречия по близости и полярности;
- 64-битные стабильные идентификаторы атомов с совместимостью со старыми;
- dry-run рационализация дублей с гейтом сохранения информации.

## Ограничения

- Исходный граф и отчёты не удаляются.
- Рационализатор остаётся dry-run по умолчанию.
- Внешний docs-toolkit только опционален; репозиторий работает без локального
  пути конкретного пользователя.
- Apply требует явных `--apply --force-truncate`.

## Критерии готовности

- `python tools/tests/test_butterfly.py` покрывает новые режимы.
- Четыре затронутых модуля проходят `py_compile`.
- `validate.py` не содержит ERROR.
