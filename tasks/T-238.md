# T-238 — Draft-code sandbox lane

## Context

The user asked whether agents may write experimental program code into a sandbox subfolder so observers and Codex can review it before any execution or promotion into the main project.

The existing sandbox policy already supports external-source quarantine and read-only intake, but it does not clearly define a separate lane for agent-authored draft code.

## Requirements

1. Add a `sandbox/drafts/` folder contract for agent-authored experimental code.
2. Keep execute off by default and require review before any run or promotion.
3. Add a reusable manifest template for draft-code proposals.
4. Keep raw draft code out of normal Git commits by default.
5. Document pros, cons, risks, and promotion flow in an outbox report.
