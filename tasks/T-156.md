# T-156 — Pipeline done --applied evidence marker

Контекст: `tools/instructions.py preflight` уже показывает агенту обязательные правила, но `pipeline.py done` пока не хранит короткую машинно читаемую отметку, какие инструкции реально применялись. Из-за этого assurance остаётся только текстовой дисциплиной в outbox-отчётах.

Критерии done:

- `pipeline.py done` принимает необязательный `--applied "..."`;
- старый сценарий `done --report` остаётся совместимым;
- `queues/done/<T-id>.done.md` получает поле `applied` в front matter и читаемую строку `Applied instructions:`;
- операторская документация показывает новый флаг;
- тест pipeline fencing покрывает запись evidence;
- `test_pipeline_fencing.py`, `test_instructions.py` и `top.py health` зелёные.
