# T-268 — автогенерируемый полный индекс инструментов в tools/README.md

## Зачем

Аудит 2026-07-02, находка C3 (HIGH): `tools/README.md` описывал 31 из 119 не-тестовых
инструментов, но подавался как «описание всех». Волна 2 сняла ложное «все» (раздел
переименован в «Ключевые инструменты», добавлена ссылка на автосписок `cli_inventory.py`) —
это C3-b. Данная задача — системная часть C3-a: ПОЛНЫЙ индекс, который не может устареть.

## Scope

- Новый GEN-блок в `tools/README.md` (например, `<!-- GEN:tools-index START/END -->`),
  который генератор заполняет полным списком не-тестовых `tools/*.py`.
- Описания брать из D-Card (`[FILE ID CARD]` → SUMMARY; после батча P8-a волны 2 визитки
  есть у всех не-тестовых инструментов) и/или классификации `cli_inventory.py`.
- Генерацию встроить в существующий генератор (`generate.py`) или отдельной подкомандой
  `cli_inventory.py --readme` — решить при реализации; ручная секция «Ключевые инструменты»
  остаётся человекочитаемой и НЕ генерируется.
- Тест: индекс детерминирован, `--check`-режим ловит устаревание (как generate.py --check).

## Acceptance

- Полный список не-тестовых инструментов виден в tools/README.md автоматически.
- Новый инструмент без записи в индексе ловится проверкой (hook/--check).
- `python tools/validate.py` и `python tools/generate.py --check` зелёные.
