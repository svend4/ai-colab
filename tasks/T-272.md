# T-272 — C33: контур safe_write, миграция по мере касания

## Зачем

Аудит 2026-07-02, находка C33 (medium): `_ioutil.safe_write` использовался в 3 из ~40
пишущих инструментов — защита от усечения файлов была точечной, контура не было.
Stefan выбрал подвариант **C33-c** (Q-W2-8, дефолт c): мигрировать высокорисковые,
у генератов оставить прямую запись с пометкой, остальное — под правило-монитор.

## Что уже сделано (волна 2, 2026-07-05)

1. **Инвентаризация** ~41 пишущего инструмента (шаг 1) — итоговые классы видны в
   `python tools/adoption.py` (строка «Write-контур (C33)») и в `--list unguarded`.
2. **Мигрированы высокорисковые** (переписывают рукописный/канонический путь целиком):
   - `tools/bulk_dcard_generator.py` — переписывает исходники tools/*.py (вставка D-Card);
   - `tools/git_reconcile.py` — merge-драйвер переписывает ours (%A) канон-файла;
     аномальное сжатие теперь не молчит: пишется с force + конфликт `size-guard` + exit 1;
   - `tools/crdt_merge.py` — `--out` часто перезаписывает ours/канон-файл; сильное сжатие
     отклоняется гвардом, намеренное подтверждается флагом `--force-truncate`.
3. **Правило-монитор** в `tools/adoption.py` (WARN): «усекающая запись по рукописному
   канон-пути (decisions/questions/topics/tasks/docs, dialog.md, AGENTS.md, PROTOCOL.md)
   без safe_write» → статус `direct-canon` в отчёте. Гашение ложных срабатываний:
   маркер `# direct-write-ok: <причина>` (10 генератов/атомарных писателей помечены)
   или реестр `WRITE_ALLOWLIST` (10 файлов, которые правят параллельные пакеты волны 2).
   Тесты: `tools/test_adoption.py`, `tools/test_bulk_dcard_generator.py`,
   `tools/test_git_reconcile.py` (size-guard-кейс).

## Что осталось (миграция по мере касания)

Файлы из `WRITE_ALLOWLIST` в `tools/adoption.py` (agent_queue, dcard_indexer, friction,
generate, pipeline, portal, reconcile_state, stream, synthesis_helper, top): при первом
содержательном касании файла — решить, safe_write это или маркер, и убрать запись из
allowlist. Цель — allowlist пустой, WARN=0 остаётся инвариантом.

## Критерий готовности

- `python tools/adoption.py --list unguarded` пуст при пустом WRITE_ALLOWLIST;
- у каждого прямого писателя по канон-пути — либо safe_write, либо маркер с причиной.
