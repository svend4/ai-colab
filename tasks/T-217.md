# T-217 — Sandbox Runner Core

Этапы 7 и 8 трека execute-sandbox.

Цель: реализовать единую точку входа для безопасного запуска контейнеров — скрипт `tools/sandbox_runner.py`.

1. Принимает аргументы `execute <driver_id> <image> <command...>`.
2. Конструирует безопасный docker run с нужными mount-ами и лимитами (на основе `docs/execute-sandbox-preflight.md`).
3. Запрашивает preflight проверки через `execute_preflight.py check-all`.
4. Оборачивает запуск в `execute_audit.py` для логирования и изоляции.
5. Запускает команду.

Этот этап завершает сборку инфраструктуры 10 гейтов безопасности.
