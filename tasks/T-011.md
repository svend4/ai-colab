# T-011 — Машинный индекс index.json

`generate.py` строит корневой `index.json` (детерминированный, без таймстампов) из front-matter всего канона: массивы `topics` / `tasks` / `questions` / `decisions`. Агент читает один индекс вместо перечитывания репозитория — снижает стоимость для нескольких ИИ. `--check` контролирует свежесть (используется в pre-commit hook).
