# T-226: Внедрение мягкой проверки метаданных

## Задача (White Path)
Нужно встроить проверку D-Cards в ядро проекта, но не ломать CI.

1. Добавить ключ `--warn-only` в `tools/enforce_metadata.py`. В этом режиме скрипт возвращает код 0, даже если есть ошибки, но выводит их в лог.
2. Подключить вызов `python tools/enforce_metadata.py --warn-only` в `tools/top.py health` (рядом с `assurance` и `drift_check`).

## Критерии приемки
- [ ] `enforce_metadata.py --warn-only` завершается с кодом 0.
- [ ] В `top.py checks/health` выводится информация об ошибках D-Cards без падения команды.
