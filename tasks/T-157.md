# T-157 — Instruction check-report accepts pipeline done applied marker

Контекст: после T-156 `queues/done/<T-id>.done.md` хранит evidence в поле `applied` и строке `Applied instructions:`, но `tools/instructions.py check-report` всё ещё ожидает только outbox-формат с заголовком `## Applied instructions` и `Checks:`. Это делает новый маркер машинно читаемым, но не принимаемым существующим verifier-командой.

Критерии done:

- `check_report_text` принимает outbox-отчёт со старым форматом;
- `check_report_text` принимает pipeline done-маркер с `applied:` или `Applied instructions:`;
- плохой отчёт без evidence по-прежнему отклоняется;
- тест `tools/test_instructions.py` покрывает оба формата;
- `python tools/instructions.py check-report queues/done/T-156.done.md` проходит;
- `test_instructions.py` и `top.py health` зелёные.
