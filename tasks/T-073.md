# T-073 — подтверждение UTF-8 вывода

Цель: зафиксировать, что предложенная процедура для Windows PowerShell решила проблему mojibake.

Пользователь выполнил:

```powershell
chcp 65001
[Console]::InputEncoding = [System.Text.UTF8Encoding]::new($false)
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
$OutputEncoding = [Console]::OutputEncoding
Get-Content -Encoding UTF8 -LiteralPath ".\PIPELINE.md"
Get-Content -Encoding UTF8 -LiteralPath ".\TASKS.md"
```

Результат: `PIPELINE.md` и `TASKS.md` отображаются читаемо на русском языке.
