# T-014 — Диспетчер задач по DAG

`tools/dispatch.py` читает `tasks/*.md` и по графу `depends_on` определяет, какие задачи **готовы** (status=todo и все зависимости done) и какие **заблокированы** (чем). `dispatch.py next` печатает id одной задачи с наивысшим приоритетом — для скриптов/агентов. Не меняет файлы; захват — через `queue.py`.

Самопроверено на DAG-фикстуре: готовые отсортированы по приоритету, заблокированные показывают незакрытые зависимости.
