# T-015 — Риск-гейтинг

`tools/risk_gate.py <id>` читает поле `risk` задачи/решения и выдаёт требуемый тир: `low → AUTO` (можно автоутвердить при зелёном каноне), `medium → REVIEW`, `high → HUMAN` (только человек, D-006). Это даёт многоуровневую автономию: человек не утверждает всё подряд, только высокорисковое.

Политика-советчик; финальное действие за человеком/сборщиком. Самопроверено (high→HUMAN, medium→REVIEW).
