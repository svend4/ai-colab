# Политика коммитов streams + commit-lock (форк по D-017)

Старый долг/новый вопрос Stefan: коммиты в общем дереве блокируют друг друга (index.lock) и рискуют
закоммитить чужую полу-готовую работу (`git add -A`); нужен промежуточный слой («ручейки»→основная линия).

Сделано (форк-вариант, на синтез с Codex):
- `темы/commit-policy-streams-2026-06-21.md` — сравнение опций (selective-add / commit-lock /
  ветка / **worktree-приток** / changeset-полуформат) + рекомендация слоями;
- `tools/commit_lock.py` (+тест) — Уровень 0: атомарный короткоживущий advisory-лок (acquire/release/
  status, O_EXCL+TTL), чтобы агенты сериализовали коммиты, а не дрались за index.lock;
- правило **selective-add** (коммить только свои файлы) против чужой half-done; полная изоляция —
  worktree (Уровень 1, требует оркестрации).
