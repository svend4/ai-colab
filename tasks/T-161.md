# T-161 — Add sub-agent launch plan to flow workflow

Контекст: в текущей среде есть возможность запускать platform sub-agent'ов, но локальный репозиторный `tools/flow.py` сам не может вызывать эту платформенную функцию. Он управляет git-ветками/worktree и merge-gate. Нужно сделать явный workflow, чтобы человек/ведущий агент мог подготовить lane в репозитории, запустить sub-agent внешним launcher'ом и получить обратно проверяемый результат без смешения обязанностей.

Критерии done:

- `python tools/flow.py launch-plan <agent> <T-id> [context...] [--worktree]` печатает безопасный dry-run план;
- план ясно разделяет repo-flow и external sub-agent launcher;
- план содержит готовый prompt для worker/sub-agent с `agent-start --context`, claim/done, tests и selective scope;
- `tools/test_flow.py` покрывает launch-plan;
- добавлен `docs/agent-launch-workflow.md` и обновлены верхние инструкции/README/capabilities;
- `test_flow.py`, `capabilities.py --check`, `top.py health` зелёные;
- task закрыт через `pipeline.py done ... --applied`.
