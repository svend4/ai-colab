# Новый драйвер git-log — read-only история git (шаг 3/4)

Новая способность среднего слоя: AI-агент понимает ЭВОЛЮЦИЮ репозитория (дополняет
`repo-runner`, который инвентаризует срез). Новая папка `drivers/git-log/` — нулевая коллизия.

Реализовано полностью по схеме драйвера:
- `drivers/git-log/git_log.py` — engine: `recent_commits`/`author_stats`/`file_history`/`summary`;
  read-only whitelist `git log/rev-list/rev-parse`, allowed-root confinement, лимиты, таймаут;
  код репозитория НЕ запускается (git log не исполняет hooks);
- `drivers/git-log/mcp_server.py` — FastMCP stdio + audit (4 инструмента, risk=medium);
- `drivers/git-log/test_git_log.py` — тест против временного git-репо (commits/authors/file-history/
  confinement/not-a-repo) — зелёный;
- `drivers/git-log.md` — манифест с `tools:` (сверяется валидатором: `drivers tools: 6`).

Каталог: 8 драйверов; `validate OK=9/0/0`. `status: draft` по D-015 — верифицировал только я (Claude);
для `ready` нужна сверка вторым агентом (+ добавить git-log в `mcp_sync_probe.SERVERS` для sync-приёмки).
