# T-010 — Валидатор v2

`validate.py` теперь дополнительно проверяет файлы-источники напрямую (`check_sources`): у каждого `tasks/questions/decisions/*.md` есть front-matter с `id`/`title`/`status`, id уникальны в реестре, имя файла = id, а `depends_on` ссылается на существующие задачи.
