# T-223: Enforce D-Cards and Layers

> Рождено из консенсуса в котле (Ratify-Build Lane)

## Задача (White Path)
Согласно консенсусу (layered-architecture, metadata-indexes), нужно сделать D-Cards (визитные карточки) обязательными.

Нужно написать скрипт `tools/enforce_metadata.py` (или доработать `dcard_indexer.py`), который будет:
1. Проверять наличие "Визитных карточек" (`# [FILE ID CARD]`) во всех файлах `tools/`.
2. Валидировать, что указаны правильные поля (`ID`, `TYPE`, `DOMAIN`, `DEPTH_LEVEL`, `SUMMARY`).
3. При отсутствии метаданных - выводить ошибку (или попытаться встроить базовую).

## Критерии приемки
- [ ] Инструмент валидации готов и не ломается на корректных карточках.
