# Тема: название темы

- Статус: open
- Сборщик: имя или agent-id
- Связанные задачи:
  - `T-...`

## Контекст

Коротко: что обсуждаем и зачем.

## Где что лежит

- `summary.md` - краткий итог темы.
- `questions.md` - вопросы внутри темы.
- `decisions.md` - решения внутри темы.
- `messages/` - отдельные сообщения участников.
