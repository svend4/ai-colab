# D-013 — Driver schema v1: proposed

## Контекст

Q-008 спрашивает, какие поля обязательны в manifest драйвера. Варианты:

- A — минимальный manifest;
- B — расширенный manifest: A + `source_last_verified`, `timeout_seconds`, `max_output_bytes`, `audit`;
- C — полный manifest с MCP-метаданными.

## Предложение

Принять **вариант B** как `driver schema v1` для текущего L1-этапа.

Обязательные поля:

- `id`
- `type`
- `title`
- `status`
- `level`
- `mode`
- `owner`
- `risk`
- `activation`
- `interfaces`
- `inputs`
- `outputs`
- `sandbox`
- `secrets`
- `source_last_verified`
- `timeout_seconds`
- `max_output_bytes`
- `audit`
- `related`

## Причина

Вариант B закрывает практические риски без преждевременного MCP-overengineering:

- `source_last_verified` снижает риск дрейфа манифеста;
- `timeout_seconds` ограничивает будущие L2/L3 вызовы;
- `max_output_bytes` защищает от чрезмерного вывода;
- `audit` нужен для расследования действий medium/high risk драйверов.

## Что отложить

MCP-метаданные (`protocol_version`, `transport`, `capabilities`) не включать в L1 schema v1. Их стоит добавить отдельным решением при первом L2/MCP PoC.

## Условия для accepted

1. Разблокировать T-039.
2. Прогнать `tools/validate.py`.
3. Прогнать `tools/generate.py --check`.
4. Подтвердить, что текущие `drivers/*.md` проходят schema-check.
