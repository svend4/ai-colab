# D-021 — Ратификация открытых котёл-пунктов (Stefan, D-006)

## Статус

`accepted`. Одобрено Stefan (D-006: человек утверждает решения) в сессии 2026-06-21 по доказательной
базе. Техническая основа — синтез Codex `D-020` (`proposed`) и независимая перепроверка
`темы/kotel-decision-material-2026-06-21.md` (двойной чек техн.+гуман., кросс-чек vs Codex, D-018/D-015).
D-021 переводит governance-часть в `accepted`; `D-020` остаётся технической записью и может ссылаться сюда.

## Решения

1. **Уровень-1 (worktree-streams) — ПРИНЯТ.** Параллельная изоляция исполнения: каждый агент в своём
   `git worktree` на ветке `agent/<agent>/<task>`. Набор готов: `tools/stream.py` (пакеты-форки) +
   `tools/merge_gate.py` (гейт) + `tools/worktree.py` (новый) + `tools/flow.py --worktree` (обвязка
   start→приток, finish→merge_gate→merge→снять). **Уровень-0** (selective-add + `commit_lock`) остаётся
   дефолтом; Уровень-1 включается явно `--worktree` при реальной параллельной нагрузке.

2. **core-export Q2 — принят набор из 10 файлов** «agent-coordination engine» (`core/engine-manifest.md`:
   canon+гейт = `_canon/validate/generate`, атомарный котёл+lock+гейт = `next_id/commit_lock/pipeline/
   dispatch/merge_gate`, 2 теста). Механизм — `promote.py export` = курируемая КОПИЯ (не move), живой
   `tools/` остаётся mainline; переносимость доказана (экспорт → standalone-тест зелёный). Драйверы и
   knowledge — ВТОРОЙ export (Q3, тянут MCP/SQLite-зависимости).

3. **apex-panel — Вариант C (фасад).** `tools/top.py` — основной вход; делегирует в `tools/cohort.py`
   для параллельных/самохостинг-сценариев (`board/plan/turn/self/ship`). Не полное слияние (ортогональная
   семантика, 20+ кнопок запутают) и не два изолированных инструмента. Реализация фасада — на стороне
   `top.py` (зона Codex), через синтез (форк `streams/apex-panel/...`), не соло.

4. **D3 (объём инфры) — C1-C3 + тонкие T-137-инструменты; §9 P1 отложен до измеренного спроса.**
   Подтверждает `D-020`: добавление нового инфра-инструмента легально только при (a) повторяющемся ручном
   трении или (b) явном запросе. Обратимо.

5. **svend4/T-020 — честный BLOCKED.** Generic external-source intake-контракт (`docs/external-code-sandbox.md`
   + `tools/sandbox.py`/`sandbox_intake_demo.py`) принят как универсальный путь. Реальный (не demo) прогон —
   когда Stefan даст read-only источник. `execute` = OFF по умолчанию (D-014, 10 preflight-гейтов).

6. **Владелец merge-gate** — Stefan или назначенный интегратор подтверждает слияние притоков в основную
   линию (консервативный дефолт; роль уточняется при первом реальном Уровне-1).
