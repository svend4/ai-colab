# D-005 — Имена новых файлов в ASCII

- Контекст: кириллические пути дают трения с git (экранирование), ссылками (percent-encoding), Unicode-нормализацией и инструментами/CI.
- Решение: новые технические и тематические файлы именуются в ASCII; кириллица — в заголовке внутри файла.
- Последствия: на момент D-005 существующие русские имена оставались как есть; их миграция уточнена D-007.
