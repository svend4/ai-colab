# D-008 — Границы D-003: что считать значимой правкой

- Контекст: D-003 требует обоснование для «значимых» правок; нужно было определить границу (Q-005).
- Решение: обоснование обязательно для значимых изменений — структура, правила, решения, задачи, статусы, протокол, права агентов, очереди, шаблоны, активные темы. Мелочи (опечатки, формат, типографика) — без.
- Последствия: журналы не засоряются обоснованиями к мелочам; важные изменения остаются прослеживаемыми.
