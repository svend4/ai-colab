# D-007 — Постепенная миграция русских имён к ASCII

- Контекст: D-005 задал ASCII для новых файлов; оставался вопрос по существующим русским именам (Q-004).
- Решение: ленивая миграция — файл с русским именем переименовывается в ASCII при следующей существенной правке, с обновлением всех ссылок; массового переименования не делаем.
- Последствия: смешанный стиль временно сохраняется и сходит на нет; ход миграции — задача T-005.
