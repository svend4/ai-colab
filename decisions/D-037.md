# D-037 — Мягкая заморозка мета-развития v2

## Статус
`accepted`. Ратифицировано: Stefan, котёл-день 2026-07-06 (HUMAN-DECISIONS-OPEN) —
ответ по Q5, вариант «мягкий / advisory» (E1). Формализует смещение фокуса с
самосовершенствования платформы на внешние L2-грузы.

## Контекст
Платформа накопила богатый инструментарий (десятки `tools/*.py`). Риск — уход в
бесконечное самосовершенствование инфраструктуры вместо реальных внешних грузов
(T-273-класс: end-to-end L2 payload на реальных данных). Q5 предлагал заморозку
мета-развития; выбран **мягкий вариант** — advisory-напоминание, а не жёсткий запрет,
чтобы не блокировать оправданные инструменты, но сместить дефолт-фокус.

## Решение
1. **Новые `tools/*.py` заводятся только при одном из двух условий:**
   - из **зафиксированной friction-боли** (запись во `friction-ledger` — по правилу отбора:
     повторилось достаточно раз и мешает после playbook), **ИЛИ**
   - по **явной потребности человека** (запрос/отмашка Stefan).
2. **Режим — advisory-напоминание, не жёсткий запрет.** Инструмент можно создать и вне этих
   условий, но напоминание фиксирует: обоснование = friction-боль или потребность человека.
   Нет авто-блокировки коммита и нет ERROR-гейта на новый tool.
3. **Цель — сместить фокус** главных агентов и роёв с мета-развития платформы на **внешние
   L2-грузы** (T-273-класс): реальные данные, реальный payload, а не ещё один инструмент об
   инструментах.

## Границы
- Это **не запрет** и **не гейт** — advisory. Оправданный инструмент (из боли или по запросу
  человека) заводится штатно.
- Существующие инструменты не трогаются; заморозка касается только **новых** `tools/*.py`.
- Порог «friction-боль» опирается на существующее правило отбора `friction-ledger`
  (наблюдение → playbook → автоматизация), а не на субъективную оценку в моменте.

## Consequences
- Дефолт-фокус смещается к внешним грузам; мета-инструменты требуют явного обоснования.
- `friction-ledger` получает роль входного гейта для новой автоматизации (мягкого).
- Риск бюрократии низкий: advisory-напоминание, не процедура согласования.
