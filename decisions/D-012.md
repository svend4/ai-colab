# D-012 — Heartbeat агентов: добровольный live-слой

- Контекст: D-011 дал динамический конвейер `pipeline.py next/status/done/fail/snapshot`. Следующий вопрос Q-012: нужен ли обязательный heartbeat/live-room.
- Решение: принять вариант **B** — добровольный heartbeat. Добавить команду `pipeline.py heartbeat`, но не требовать её для каждой задачи.
- Реализация: каждый агент пишет собственный файл `logs/heartbeat/<agent>.json`; агрегированные снимки генерируются в `LIVE.md` и `logs/heartbeat.json`.
- Причина: один общий live-файл с параллельной записью стал бы горячим файлом и источником конфликтов. Per-agent JSON сохраняет живость и снижает конфликтность.
- Когда пересматривать: если одновременно стабильно работают 3+ агента или появляются долгие задачи с ожиданием ETA, можно поднять вопрос об обязательном heartbeat.
