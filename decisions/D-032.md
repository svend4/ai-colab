# D-032 — gap_scan.py: исполняемый детектор разрывов «замысел ↔ реальность»

## Статус
`accepted`. Ратифицировано: Stefan, 2026-07-06 (котёл-ответ по human-actions-plan, блок A) —
формализация ранее сказанного: Stefan авторизовал внедрение в сессии 2026-06-26 («Да внедрить это
полностью подробно детально»); формальный флип в `accepted` был оставлен человеку — чтобы не плодить
auto-accept без явного следа (предостережение самой формулы, §6 п.6). Развивает
[[defect-class-formula-2026-06-26]] (пока `proposed`-топик без исполняемой руки) и дополняет D-031.

## Контекст (разрыв, пойманный вживую)
`defect-class-formula` назвала симптом **(f) тихий дрейф деривата** самым коварным и **открытой
проблемой #1**: дериват (счётчик/индекс/портал) МОЛЧА читает несуществующий путь после ре-нейминга
источника и возвращает 0 — **немой ноль выглядит как валидный ответ**. Но формула была *документом*:
- исполняемого детектора не было (только `mutmeta` для со-дефектных тестов, C-III);
- живой баг подтверждён: `metrics.py:77 load("темы")` → `topics total = 0` при 75+ темах на диске;
- D-031 *решил* сделать `commit_queue` стандартом, но сам `commit_queue` остался **orphan** (ничто его
  не вызывает) — «решено, но не подключено» = тот же класс на уровне governance.

То есть три формы одного разрыва: **построено-но-не-подключено** (orphan), **решено-но-не-исполнено**
(unenforced), **описано-но-не-закодировано** (dangling/uncoded). Их никто не искал механически.

## Решение
1. **`tools/gap_scan.py` (+ `test_gap_scan.py`)** — исполняемая «формула» из трёх детекторов:
   - **orphans (G1):** `tools/*.py`, на который не ссылается ни import, ни CLI в docs/PROTOCOL/AGENTS/
     skills/хуках/top, ни `tools/README` (только сам файл и его `test_`). Архетип — `commit_queue`.
   - **drift (f):** мёртвые литералы каталогов (AST string-const, не докстринг) — напр. `"темы"` (теперь
     `topics/`), из-за которых дериват молча читает несуществующий путь.
   - **dangling (G5):** ссылки на `tools/<name>.py` в доках, где файла нет (напр. `queue.py`).
   CLI: `gap_scan.py [orphans|drift|dangling] [--json] [--strict]`.
2. **Починен живой дрейф (f):** `metrics.py`, `promote.py`, `instructions.py`, `layer_check.py`:
   `"темы"`→`"topics"`; де-со-дефектнут `test_metrics.py` (фикстура писала в `темы/` — тест зеленел
   поверх бага, C-III). Проверка: `metrics.py` теперь `Темы: 75` (было 0); `gap_scan drift` = 0.
3. **Гейт против рецидива:** `pre-commit` запускает `gap_scan.py drift --strict` и **блокирует коммит**
   на любом мёртвом литерале каталога (fail-open на ошибке инструмента). Реализует «пустой результат от
   несуществующего пути → ERROR, не 0» из формулы (§6 п.1) на уровне гейта.

## Перепроверка (D-018)
- **Техническая:** `test_gap_scan.py` зелёный; ручная мутация (`if not referenced`→`if referenced`)
  → тест краснеет (детектор не со-дефектен по сути). `mutmeta gap_scan` = 0.0 — но это **ограничение
  самого `mutmeta`** (мутирует только `==`/`True`/`return`/литералы, не `in`/regex/`startswith`, что и
  использует gap_scan): честно, а не скрытый со-дефект. → follow-up: расширить операторы `mutmeta`.
- **Гуманитарная:** делает невидимый класс разрывов ВИДИМЫМ и БЛОКИРУЕМЫМ (для drift); не повышает
  поверхность риска (orphans/dangling — advisory-отчёт, гейтится только точный AST-drift).

## Boundaries (что НЕ сделано — честно)
- **orphans/dangling — advisory**, не гейт (есть ложноположительные: новые экспериментальные тулы,
  человеко-CLI). Гейтится ТОЛЬКО `drift` (точный, AST, 0 FP после фикса).
- **commit_queue (D-031) всё ещё не вшит** в `conveyor.py`/`top.py`/инструкции агентов — `gap_scan`
  теперь это ДЕТЕКТИРУЕТ (orphan), но автоматически коммитить через очередь нельзя заставить хуком
  (post-hoc не видно, прошёл ли коммит через очередь). Адопшн = конвенция + D-031 + helper, не enforcement.
- **Глубокий фикс (f)** — единый реестр `CANON_DIRS`, который деривативы импортируют вместо литералов —
  follow-up (сейчас точечный фикс + гейт против рецидива).

## Consequences
- Появилась исполняемая рука формулы: разрывы замысел↔реальность ищутся одной командой и блокируются.
- Закрыт живой баг `metrics topics=0`; класс (f) не рецидивирует молча (гейт).
- Инвентарь разрывов — `reports/gap-inventory-2026-06-26.md`.
