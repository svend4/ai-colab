# D-002 — Для больших тем использовать отдельный файл на сообщение

- Контекст: в одной теме могут одновременно писать много людей, AI-агентов и скриптов.
- Решение: большая тема ведётся папкой `темы/<topic>/` с `messages/`, где одно сообщение = один файл.
- Последствия: снижается риск конфликтов записи; итог собирается отдельно (`summary.md`, общие файлы).
