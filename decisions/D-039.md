# D-039 — worktree-изоляция обязательна при N≥3 + потолок одновременности

> **Ратифицировано: Stefan, котёл-день 2026-07-07.** Принято по итогам диагноза насыщения
> машины (reports/machine-saturation-diagnosis-2026-07-07.md) и обсуждения.

## Решение

Многоагентная работа подчиняется ДВУМ ортогональным гейтам (docs/worktree-isolation-enforcement-2026-07-07.md):

1. **Гейт A — worktree-изоляция.** При одновременности **N≥3 активных агента worktree
   ОБЯЗАТЕЛЕН** (коммит в общий `main` отклоняется — `tools/worktree_gate.py` в `commit.py`
   и pre-commit переключается из advisory в BLOCK по факту принятия этого решения). При N<3 —
   рекомендуется (advisory WARN). Порог N=3 = точка насыщения (ядра−запас на текущей машине).

2. **Гейт B — потолок одновременности + очередь.** Число одновременных тяжёлых агентов
   ограничено CAP ≈ (ядра − запас); лишние встают в ОЧЕРЕДЬ (`tools/work_admission.py acquire`
   возвращает QUEUE), а не грузят машину. Кто раньше взял слот — тот работает; остальные ждут.

## Обоснование

- **Техническое:** общий рабочий дерево + тяжёлый validate на каждом коммите при 3+ агентах
  насыщает CPU/диск (доказано: пустой `.git/worktrees/`, таймауты git). Изоляция убирает
  коллизию дерева; CAP убирает CPU-перегрузку. Нужны оба — worktree сам не ограничивает число.
- **Теоретическое (уточнение Stefan):** изоляция — физический субстрат independent-first
  (D-028): каждый агент пишет СВОЮ версию полностью, не глядя на других и не перебивая,
  реализует свой потенциал; затем варианты сверяются (reconcile/D-029). Перегрузка машины и
  потеря независимости — один дефект общего дерева; изоляция чинит оба.

## Enforcement

- **Гейт A** `tools/worktree_gate.py` (RATIFY_DECISION=D-039) — при accepted этого решения `--hook`
  возвращает BLOCK на «общий main + N≥3». Вызывается в `commit.py` И в `tools/githooks/pre-commit`
  (T-297), поэтому ловит и сырой `git commit`. Обход только `--no-verify` (запрещён commit-safety-standard).
- **Гейт B** `tools/work_admission.py` — слоты/очередь; написан и протестирован, но пока
  вызывается ВРУЧНУЮ. Автоинтеграция в `top.py take`/`pipeline claim` — открытая задача **T-297**
  (до неё Гейт B не принуждается на choke point).
- CI дублирует полноту (bulk-guard.yml).

## Соразмерность
1 агент — свободно; 2 — рекомендуется; ≥3 — обязательно. Ограничение включается только там,
где изоляция объективно лучше для всех.
