# Q-018 — ФУНД-A: что есть «ядро» и где граница?

Фундаментальный вопрос Stefan (2026-06-24). Зарегистрирован как Q-карточка (DIV-19: 5 фунд-вопросов
не были в реестре — слепое пятно).

**Ответ (свод §1, §5):** ядро — **file-native движок координации агентов**: один файл = одна единица
знания, front-matter — единственная правда, агрегаты генерируются, инварианты принуждаются хуком,
поверх пирамиды **L1 core → L2 portals → L3 collab → L4 sandbox** (D-016). Граница L1 — `core/engine-manifest.md`
(8 engine-tools + candidates), проверяется `layer_check.py`. Доменное не загрязняет ядро — оно в L2-порталах.

**Остаток (~35%):** точная граница «что L1, что L2» доводится промоушенами (`promote.py` gate L2→L1,
knowledge.py — второй core-export, T-207). См. `topics/architecture-fundamentals-2026-06-24.md §1`.
