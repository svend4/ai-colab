# Q-019 — ФУНД-B: визитка файла

**Ответ (свод §2):** каждый файл несёт **визитку** (card→middle→base) вверху — для .md front-matter
(id/type/title/status/**gist**), для .py module-docstring. Стандарт — `docs/card-standard.md`,
инструмент — **`tools/header.py`** (`card`/`lint`/`board`). **Покрытие 213/214** (`header.py board`).
Завирён в блок `structure`. Реализовано (~70% → выше: остаток — миграция последних файлов + sidecar для не-md/py).
