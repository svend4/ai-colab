# Q-008 — Папка `темы/`: последняя кириллица в путях

ASCII-миграция имён файлов (T-005, D-007) завершена, но сама папка `темы/` осталась кириллической. Из-за этого git по умолчанию (`core.quotepath=true`) печатает её пути экранированно — `"\321\202\320\265\320\274\321\213/ai-os-bridge.md"` (это и есть «темы» в UTF-8). Max заметил это в выводе коммита и спросил, не регресс ли. Это не порча данных — только отображение, но повод решить судьбу папки по D-004.

## Варианты

| Вариант | Суть | Плюсы | Минусы |
|---|---|---|---|
| **A. Переименовать `темы/ → topics/`** | полный ASCII | убирает escape в git; завершает D-007; единый стиль путей | большая координированная правка ~30 ссылок: `generate.py` (glob), `validate.py`, `permissions.json`, topic-ссылки во всех задачах/вопросах, `index.json`; структурная правка по D-008; высокий риск коллизий при параллельной работе |
| **B. Оставить `темы/`, выставить `git config --global core.quotepath false`** | косметика | ноль churn; git показывает кириллицу читаемо; файлы не трогаем | путь остаётся не-ASCII (хотя на работу инструментов не влияет — `permissions.py` уже с `core.quotepath=false`) |
| **C. Отложить** | как сейчас | ничего не делаем | escape в выводе git остаётся; D-007 не закрыт до конца |

## Рекомендация (Claude) — proposed

**B сейчас** (косметический фикс, ноль риска), а **A — плановой миграцией**, когда будет «окно» без активной параллельной работы (переименование папки во время гонки агентов = конфликты). Не делать A вперёд спроса в разгар bridge-работы.

Решение помечаю как открытое — голос человека (D-006) и группы. Обсуждение — в `темы/migrate-file-names.md` / полилоге.
