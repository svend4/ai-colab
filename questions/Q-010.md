# Q-010 — Папка `topics/`: последняя кириллица в путях

> История id: заводилось как Q-008, затёрто параллельным Q-008 Mavis (manifest schema); пересоздано как Q-009, но Q-009 ранее застолблён Novax (svend4) в полилоге. Итог — Q-010.

ASCII-миграция имён файлов (T-005, D-007) завершена, но сама папка `topics/` осталась кириллической. Из-за этого git по умолчанию (`core.quotepath=true`) печатает её пути экранированно — `"\321\202\320\265\320\274\321\213/ai-os-bridge.md"` (это «темы» в UTF-8). Max заметил это в выводе коммита. Это не порча данных — только отображение, но повод решить судьбу папки по D-004.

## Варианты

| Вариант | Суть | Плюсы | Минусы |
|---|---|---|---|
| **A. Переименовать `topics/ → topics/`** | полный ASCII | убирает escape в git; завершает D-007; единый стиль путей | большая координированная правка ~30 ссылок: `generate.py` (glob), `validate.py`, `permissions.json`, topic-ссылки во всех задачах/вопросах, `index.json`; структурная правка по D-008; высокий риск коллизий при параллельной работе |
| **B. Оставить `topics/`, выставить `git config --global core.quotepath false`** | косметика | ноль churn; git показывает кириллицу читаемо; файлы не трогаем | путь остаётся не-ASCII (на работу инструментов не влияет — `permissions.py` уже с `core.quotepath=false`) |
| **C. Отложить** | как сейчас | ничего не делаем | escape в выводе git остаётся; D-007 не закрыт до конца |

## Рекомендация (Claude) — proposed

**B сейчас** (косметика, ноль риска), **A — плановой миграцией**, когда будет «окно» без активной параллельной работы. Не делать A вперёд спроса в разгар bridge-работы. Голос — за человеком (D-006) и группой.

## Подтверждение + план миграции (флот, 2026-06-23)

Воркфлоу подтвердил рекомендацию, но **уточнил масштаб A**: не «~30 ссылок», а **268 git-tracked файлов /
956 строк** — 27 файлов в самой папке, 138 строк `topic: topics/...` во front-matter задач, и **19+
hardcode-литералов `темы`** в ~14 модулях (`generate.py:55` glob, `variants.py:45`, `validate.py:219`,
`assurance.py:52`, `conveyor.py:36`, `repo_search.py:28`, `cohort.py:40`, `ownership.py:29`,
`permissions.json:8/28`, …). `core.quotepath` уже глобально `false` → **B закрывает косметику сейчас с
нулём риска** (инструменты иммунны — `permissions.py` пинит `-c core.quotepath=false`).

**A — одним атомарным коммитом в окно без активной работы (D-008):** `git mv темы topics` (27 файлов) +
скриптовый sweep `topics/`→`topics/` по 268 файлам + правка 19 hardcode-литералов + `generate.py` regenerate
+ `validate.py`/тесты + закрыть D-007. Делать A в разгар параллельной работы = максимальная площадь
конфликтов и риск тихо сломать generate/validate/permissions при пропущенном hardcode.
