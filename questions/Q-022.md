# Q-022 — ФУНД-E: портабельность

**Ответ (доказано; был ~45% — единственный фунд <50%, теперь закрыт):**
Рабочая папка **переносима (clone-and-run + 1 bootstrap)**. Доказано acceptance-тестом
**`tools/portability_check.py`** (вариант 1 ниже реализован).

## Что показал тест (git-archive HEAD = точная модель свежего clone)
1. **Сырой clone ДО setup:** `validate` rc=1, ERROR=2 — отсутствуют 2 **генерируемых снимка**:
   `PIPELINE.md` (untracked) и `logs/pipeline.json` (gitignored, .gitignore §15). Их требует
   `validate.py::check_pipeline_d011` (артефакт-presence D-011).
2. **Bootstrap (1 команда, как `npm install`):** `python tools/pipeline.py snapshot` — воссоздаёт оба.
3. **После bootstrap:** `validate` rc=0, `generate --check` rc=0, **хардкода хост-путей в tools/ — ноль**.

→ **ВЕРДИКТ: ПОРТАБЕЛЬНО** (все пути из `__file__`/`COLLAB_ROOT`; ни одного абсолютного хост-пути;
единственная пост-clone зависимость — регенерируемый снимок, не хост).

## Остаток (косметика, не блокер)
2 генерируемых снимка gitignored/untracked → свежий clone нуждается в bootstrap. Альтернатива —
сделать D-011-проверку толерантной к «снимок отсутствует → подсказать snapshot», но это ослабление
enforcement accepted-решения → **через cauldron, не односторонне**. Текущий ответ — документировать
bootstrap; ядро отдельно переносимо через `promote.py export --manifest`.
