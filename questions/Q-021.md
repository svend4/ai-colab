# Q-021 — ФУНД-D: нумерация + внутрифайловая навигация

**Ответ (свод §4):** длинный файл — **дерево** (метаданные/ToC → тело → хвост, общее→частное), крупные
доки несут **абсолютную dotted-decimal нумерацию** (1, 1.2, 1.2.3). Линтер — **`tools/heading_check.py`**
(пустые заголовки, пропуск уровней, крупные доки >300 строк без нумерации — нашёл 9). Завирён в блок
`structure`. Остаток — авто-нумерация существующих 9 крупных доков (build/migration).
