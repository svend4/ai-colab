# Q-014 — домен vs generic (расхождение D2/D1 синтеза мнений)

Расхождение Claude↔Codex: строить доменный слой (юр-workbench) или оставаться универсальным.

## Итог (Stefan, 2026-06-21)

**Универсальное ядро.** Домен (юр/соц/любой) — как **портал/плагин/под-тема** поверх ядра, по
модели Википедии (универсальная энциклопедия + тематические порталы = узкоспециализированные
подпапки/под-темы workbench). Зафиксировано в **D-016**.

- D2 → generic-ядро; домен — портал-плагин (не в коде ядра).
- D1 (text-extract) → генерик-способность ядра (нужна для реальных PDF/DOCX в любом портале).
- Следующий шаг: генерик-механизм порталов (`tools/portal.py`).
