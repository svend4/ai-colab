> **Установка (по просьбе):** СНАЧАЛА формулируем вопросы (этот документ), ПОТОМ отвечаем. Цель —
> вопросник, на который потом можно отвечать **автоматически** (тул классифицирует артефакт → его
> триаду → предлагает варианты). Принцип: троица **частный · средний(гибридный, золотая середина) ·
> глобальный**, повторяющаяся ФРАКТАЛЬНО (Серпинский) на каждом уровне. Легенда: ✅ есть · 🔶 частично · ⬜ открыто.

## Раздел 3. Триада ВНУТРИ каждого артефакта (фрактал внутрь — главный вопрос)
3.1. Есть ли внутри файла **3 уровня** (общее → среднее → детальное)? 🔶 (для .md)

3.3. **ГЛАВНЫЙ ВОПРОС: почему та же 3-уровневая пирамида НЕ применяется к КОДОВЫМ файлам (.py)?** ⬜
  3.3.1. Можно ли в .py сгруппировать **3 больших слоя**: сверху общие/малые команды (API, точки входа) → середина (средние функции) → низ (большое детальное тело/реализация)? ⬜
  3.3.2. Что мешает 3 уровням внутри Python — язык? соглашение? инструменты? ⬜

**Вопрос 5.1.** Должна ли память нормы быть триадной: агентная, кластерная, глобальная?

**Ответ:** да как proposed model: agent memory фиксирует локальный опыт, cluster/portal memory фиксирует закономерность группы, global memory фиксирует норму/решение.

**Статус:** частично решено; требуется схема и инструмент.

**Вопрос 5.3.** Где золотая середина в иммунной памяти?

**Ответ:** в кластерной/портальной памяти: она не такая узкая как память одного агента и не такая жёсткая как глобальная норма.

**Статус:** частично решено.
