# Патч-совет svend4/infon (TVCP)

> Стадия 4. Конкретные правки ВАШЕМУ TVCP по фактически прочитанным файлам (fetched-снапшот в
> sandbox/tvcp_fetched). Строки — по этому снапшоту; Go здесь не компилировался → сниппеты
> ИЛЛЮСТРАТИВНЫ (форма правки, не готовый diff). Порядок: безопасность → детерминизм → честность → новый режим.

# 1. 🔴 `scene.Apply` — санитизировать ГЕОМЕТРИЮ каждого op (DoS от чужого мозга)
**Где:** `pkg/scene/scene.go:75` `Apply`; `case "rect"` (`:85`) и `case "disc"` (`:126`) гоняют циклы по СЫРЫМ
`op.W/op.H/op.R` из JSON. `RenderScene` (`:142-154`) клампит ТОЛЬКО канву, не op. Внешний `BRAIN_URL`
(объявлен недоверенным, §14) может вернуть `W=1e9` или `R=1e9` → цикл на миллиарды итераций (зависание),
или отрицательные → мусор. Это единственная брешь в вашей же образцовой clamp-дисциплине (`clampi`/`Color()`).

```go
// в начале Apply, рядом с черпанием op (иллюстративно):
clip := func(v, lo, hi int) int { if v < lo { return lo }; if v > hi { return hi }; return v }
// в case "rect":
x0 := clip(op.X, 0, f.Width); y0 := clip(op.Y, 0, f.Height)
x1 := clip(op.X+op.W, 0, f.Width); y1 := clip(op.Y+op.H, 0, f.Height)
for yy := y0; yy < y1; yy++ { for xx := x0; xx < x1; xx++ { f.SetBlock(xx, yy, g, fg, ...) } }
// в case "disc": r := clip(op.R, 0, max(f.Width, f.Height))
```
Тест: `Apply` со `{op:rect,w:1<<30,h:1<<30}` завершается мгновенно и не пишет вне `f`.

# 2. 🟠 `Grid.pal` — гонка при параллельном рендере (ВЕРИФИЦИРОВАТЬ)
**Где:** `pkg/pseudo/grid.go:19` поле `pal Palette` на `*Grid`. Я читал только путь ЧТЕНИЯ (`resolve(g.pal,…)`);
ПУТЬ ЗАПИСИ (`g.pal = …` при анмаршале/SetPalette) не видел — **проверьте**. Если палитра ставится per-render
на общий `*Grid`, два параллельных рендера = data race (`go test -race` поймает).
**Фикс:** не хранить палитру на структуре — передавать параметром в `rect()/frame*()/diffuse()`:
```go
func (g *Grid) frameSmooth(pal Palette, cols, rows int) *terminal.Frame { cells, sw, sh := g.rect(pal); … }
```
Так `*Grid` остаётся неизменяемым описанием; палитра — аргумент вызова. (Если запись уже не на общий указатель — снять пункт.)

# 3. 🟠 `DiffuseFrames` — golden-тест детерминизма
**Где:** `pkg/pseudo/grid.go:105-142`. Детерминизм заявлен докстрингом (`rand.NewSource(1)`, `alpha=i/(steps-1)`,
`rad=maxRad*(1-alpha)`), но НИЧЕМ не зафиксирован → молчаливый дрейф при рефакторе. Это та же дисциплина, что
вы советуете везде; примените к себе:
```go
func TestDiffuseFramesGolden(t *testing.T) {
    g := &Grid{Rows: [][]string{{"navy","gold"},{"teal","gold"}}}
    fr := g.DiffuseFrames(16, 8, 4)
    h := sha256.Sum256(framesBytes(fr))            // стабилизировать байты RGBA всех кадров
    if hex.EncodeToString(h[:]) != "<pinned>" { t.Fatalf("DiffuseFrames дрейфанул: %x", h) }
}
```
То же для `rect()` ragged-входа и `upscaleBilinear`. (Вы это просите у других — закрепите свой «эталон».)

# 4. 🟡 `Grid.rect():43` — «extend last color» молча придумывает данные
**Где:** `grid.go:37-44` для рваной строки добивает ПОСЛЕДНИМ цветом соседа. Для пикселей терпимо, но это
«дорисовка» неуказанного → в семантических применениях (Q6/смысл) вводит в заблуждение. Минимум —
задокументировать в докстринге `rect`; лучше — добивать явным `defGridColor` (как пустую ячейку), а не цветом-соседом:
```go
case len(row) > 0: tok = "" // было: row[len(row)-1]; пусть пустое → defGridColor, не выдуманный сосед
```

# 5. 🟠 raymeet — общий мир без CRDT (ко-авторство тонет в last-writer)
**Где:** `docs/SHARED_WORLD.md:99-101` — host = ЕДИНСТВЕННЫЙ автор, гости реконструируют; `/place crystal`
кладёт объект «для всех» по проводу — но при конкурентных `place`/`remove` от разных режиссёров это
last-writer (или воскрешение удалённого — тот же класс, что мы чинили у себя в `crdt_merge`).
**Фикс — OR-Set + tombstone на множество объектов/регионов мира:**
```go
type ObjID string
type WorldSet struct { adds map[ObjID]map[Tag]Obj; rems map[ObjID]map[Tag]struct{} } // OR-Set
// place: add с уникальным Tag = sha256(actor|obj|lamport)
// remove: гасит НАБЛЮДЁННЫЕ теги; объект жив, если есть add-тег без remove-тега
// merge двух миров: union(adds), union(rems) → SEC, без воскрешения, без потери конкурентного place
```
Это превращает «walk the same world» в по-настоящему МНОГО-режиссёрское ко-творчество (наш T-264-урок → вам).

# 6. 🟠 Безопасность мозга: подпись Response, verify MUST, rate-limit
- `ai/BRAIN_PROTOCOL.md`/§10: подпись (`pkg/sign`) есть для записей реестра, но **сам Response мозга не подписан**
  и `uid` в мульти-агент-сценарии самозаявлен. Поднять §10 verify со SHOULD до **MUST** для high-stakes; подписывать
  `(actor, kinds, body-hash)` HMAC; неподписанный мозг = недоверенный.
- `/v1/decide` без **rate-limit** → один кривой/враждебный мозг вешает хаб. Добавить per-endpoint бюджет + таймаут.
- Добавить `SECURITY.md`: модель угроз «вредоносный BRAIN_URL» (sanitise/clamp у вас уже есть — задокументировать)
  + промпт-инъекция в `prompt`/`state`.

# 8. 🟢 НОВЫЙ РЕЖИМ: `tvcp-canvas/1` — текст-канва рядом с видео (прямое опыление от нашей работы)
Сильнейший рост: добавить рядом с видео-режимом **семантическую текст-канву** — то, что мы построили
([[textscene-unified-spec-2026-06-26]]). Вместо пиксельной сетки — сетка ТИПИЗИРОВАННЫХ ЯЧЕЕК:
- протокол `tvcp-canvas/1` (JSON, как `tvcp-ai/1`): `text_cell.v1` + `text_frame.v1` (changed_cells = ваш frame/diff);
- рендеры в духе ваших режимов: plain / ANSI-боксы / dense (sextant) / HTML-export;
- мозг ПРЕДЛАГАЕТ ячейки (proposal-only), не исполняет; добавить `input_hash`/`context_hash` в запрос;
- демо: несколько агентов правят общую текст-доску (не видео) — «совместная разработка в терминале».
Это даёт TVCP второй убойный кейс (мульти-агентная работа), переиспользуя ВАШИ же примитивы (terminal-рендер,
swap-brains, frame/diff, P2P-транспорт для бандлов событий — поздним этапом).

# 9. Приоритет
1 (DoS-clamp) → 6 (подпись/rate-limit) → 5 (raymeet CRDT) → 3 (golden) → 2 (race verify) → 7 (док-дрейф) →
4 (rect) → 8 (новый режим, стратегический). Пп. 1–6 — гигиена много-агентности; п. 8 — рост.

# 10. Оговорка
Правки по fetched-снапшоту (sandbox/tvcp_fetched), не по живому HEAD и без компиляции — это ФОРМА правок и
направление, верифицировать на месте (`go test -race ./...`, golden-пины). Главный сквозной совет тот же, что
и по идее: сделать оракула-режиссёра и доверие ВИДИМЫМИ/кворумными, а геометрию/детерминизм — зажатыми и закреплёнными.
