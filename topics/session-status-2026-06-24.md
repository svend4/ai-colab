# 1. Что построено (технически)

## 1.1. Масштаб
- **72 инструмента** `tools/*.py` + **77 тестов** (покрытие >1:1), **~24 400 строк** Python.
- Канон: **238** задач done (+1 doing), **25** решений (23 accepted), **22** вопроса (все answered, Q-001..022),
  **52** темы, **118** доков.
- Контракт принуждается: `validate.py` (0 ERROR) + `generate.py` + **pre-commit hook**.

## 1.2. Само-улучшающая машина (главный результат серии)
Замкнутый контур «найти → предложить → гейт», все части построены и проверены тестами:
```
  НАЙТИ проблемное/недозрелое        →  ПРЕДЛОЖИТЬ починку  →  ГЕЙТ/ПЕТЛЯ
  edges.py   (граф: циклы/висячие/изоляты)   autolink.py        блок structure (edges=gate)
  decay.py   (время: stale-активные)         (type/gist/topic)  блок improve (decay/adoption/
  maturity.py(синтез зрелости 0-1000‰)                          propagation/friction — advisory)
  adoption.py(применяемость машинерии)
  friction.py(event-лог повторов→лестница)
```
- **8 блоков** (`blocks.py`): audit · adoption · self · improve · propagation · pyramid · execute-preflight · structure.
- Кросс-валидация: 4 независимых инструмента (edges-изоляты / decay-stale / maturity-developing /
  autolink-backfill) **сходятся на одних** проблемных атомах — согласованная картина, не разрозненные сигналы.

## 1.3. Три оси над одними атомами (хранилище не трогается)
| Ось | Вопрос | Инструмент | Команды |
|---|---|---|---|
| Дерево | ГДЕ живёт | dir_health / folder_index | пороги папок, indexes/ |
| Граф | КАК связан | **edges.py** | check · stats · neighbors · **impact** (blast-radius) · **path** |
| Время | НАСКОЛЬКО свеж | **decay.py** | температура hot/warm/cold + stale-активные |
| *синтез* | зрелость | **maturity.py** | 0-1000‰ по 5 осям |

# 3. Концептуальная модель (статус концепции)

1. **Пирамида L1→L4** (D-016): core(L1) → portals(L2) → tasks/decisions/questions/streams/topics(L3) →
   sandbox(L4); промоушен `promote.py` с гейтами. **Зрелость концепции: высокая** (закреплена, проверяется `layer_check`).
2. **Три ортогональные оси** (дерево/граф/время) — **новая зрелая модель** этой серии: одни атомы,
   три проекции, ни одна не меняет хранилище. Документирована (typed-link-graph, time-axis-decay).
3. **Карточка-визитка** (card→middle→base, `docs/card-standard.md`): каждый файл несёт машиночитаемую
   шапку; средний слой «меню решений» для подачи человеку. Зрелость: стандарт + инструменты (header/card/decision_menu).
4. **FINDER→router→SOLVER + двухтрековый котёл:** поиск проблем воркфлоу → роутер (я) → построение;
   котёл с двумя дорожками (консенсус→ратифицировать / разногласия→детализировать). Отработано многократно.
5. **Self-reflection методичка** (`docs/sandbox-self-reflection-methodology.md`): Уровень-1 (статический
   intake) + **Уровень-2 (adversarial-критик)** — вскрывает бреши в самих инструментах (кейс: edges.py
   «0 висячих» прятал 29 тем). Официальный алгоритм для любого агента.
6. **Governance:** D-006 (человеко-гейт high-risk), D-018 (двойная перепроверка), котёл для accepted-решений.

> Концептуально проект самоосознан: он **измеряет и улучшает сам себя** своими же инструментами, и
> **рефлексирует над достоверностью** этих измерений (Уровень-2). Это зрелая рекурсивная модель.

# 6. Фундамент для дальнейшего развития

**На чём стоять дальше:**
- Само-улучшающий контур + 3 оси — **готовая платформа** для следующих детекторов/композитов (новый
  сигнал = +1 инструмент в блок, без переписывания).
- Методичка Уровня-2 — **способ не доверять своим зелёным галочкам** (применять при каждом крупном росте).
- Граф `impact/path` — **управление каскадом**: перед правкой хаба видно радиус поражения.

**Рекомендованные следующие шаги (по приоритету):**
1. **Композит осей:** `cold-хаб` (decay×edges) — холодный атом с большой in-степенью = риск (многие
   зависят от застывшего). Read-only, естественно.
2. **Авто-роутинг находок:** maturity/edges/decay → автоматические ROUTE-предложения через autolink.
3. **Governance-трек (с человеком):** выбрать DIV-20 / DIV-05 / DIV-17, спроектировать, провести котлом.
4. **execute-sandbox:** при готовности — human first-run по preflight (D-014).

> **Вывод:** ядро и само-улучшение — зрелы и работают; концепция оформлена в чёткую модель (3 оси +
> пирамида + рефлексия). Это не финал, а устойчивый фундамент: безопасный инструментальный рост почти
> исчерпан, дальнейшее развитие идёт через governance-решения и осознанный risk-фронтир.
