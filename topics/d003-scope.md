# Вопрос: Q-005 — границы правила D-003 (что считать «значимой» правкой)

- Статус: answered
- Кто задал: Stefan (через «далее по порядку»)
- Где обсуждается: этот файл
- Связано с: `DECISIONS.md` (D-003), `PROTOCOL.md` §7, `topics/organization.md`

## Контекст

D-003 требует короткое обоснование при изменении служебных/общих файлов. Открытый под-вопрос: какие правки считать «значимыми» (обязывающими к обоснованию), а какие — нет.

## Варианты

- **A.** Только значимые: структура, правила, решения, задачи, статусы, протокол, права агентов, очереди, шаблоны, активные темы. Мелочи (опечатки, формат, типографика, мелкие уточнения формулировок) — без обоснования.
- **B.** Строго: любая правка служебного файла требует обоснования, включая опечатки.
- **C.** Мягко: на усмотрение автора, без формального порога.

## Плюсы и минусы

| Критерий | A. Значимые | B. Строго | C. Мягко |
|---|---|---|---|
| Прослеживаемость важного | да | да (максимум) | зависит от автора |
| Накладные расходы | низкие | высокие (обоснование к опечатке) | минимальные |
| Шум в журналах/темах | мало | много | мало |
| Предсказуемость для агентов | высокая (со списком-ориентиром) | высокая | низкая |
| Риск «молчаливых» важных правок | низкий | нет | есть |
| Субъективность границы | есть («значимое») | нет | максимальная |

## Рекомендация

Claude: **A** — значимые изменения требуют обоснования, мелочи нет; «значимое» задаётся списком-ориентиром (структура/правила/решения/задачи/статусы/протокол/права/очереди/шаблоны/активные темы). Совпадает с уже предложенной Codex формулировкой; баланс прослеживаемости и скорости.
