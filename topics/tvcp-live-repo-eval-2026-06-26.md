> отдаёт (другой хост). И живой репо — **НЕ** тот `.inf`/infon-граф, что я оценивал по 13 загруженным файлам
> ([[infon-repo-independent-eval-2026-06-26]]). Живой `svend4/infon` = **TVCP — Terminal Video Communication
> Platform** (Go, ~120 cmd / ~50 pkg), автор — **Stefan Engel (stefan.engel.de@gmail.com)** = вы. Это ваш
> собственный репо. Прочитано вживую: README, docs/CONCEPT_MAP, REPOSITORY_REVIEW, ai/BRAIN_PROTOCOL,
> docs/SHARED_WORLD, PSEUDO_IMAGE. Оценка ниже — по фактическому состоянию, не по загруженным `.inf`.

# 1. Что это на самом деле (и связь с .inf)
TVCP: видеосвязь внутри терминала (Unicode-кварт-блоки `.babe`-кодек, 382 kbps vs 1.8 Mbps Zoom, P2P через
Yggdrasil, headless). Поверх него выросла **ray/Q6/alife-платформа** (серия блоков A–L + raypipe). Идеи из
`.inf`, что я оценивал, **впитаны сюда**:
- **Q6** → `raydir.Hexagram` (6-бит куб: Flip/Neighbors/Antipode/Hamming/**GrayWalk**) + `SceneVector` (6 Q6-float)
  как **мост «смысл↔мир»**. 6 бит = 64 ячейки = «64-world Gray-tour atlas», «Q6-hypercube roguelike». Тот же Q6.
- **pseudo-diffusion** → `PSEUDO_IMAGE.md`: текст-модель без image-head рисует через крошечный JSON-грид →
  upscale+blur → painterly-кадр; `Grid.DiffuseFrames` = denoising-анимация. **Это и есть ваша идея «текст течёт
  по типу видео» — уже реализована.**
- **swap-brains** → `tvcp-ai/1` (BRAIN_PROTOCOL): любой NN за одним JSON-over-HTTP контрактом.

# 2. Документация — оценка
- ➕ **CONCEPT_MAP.md — образцовый «смысловой срез»**: не аудит, а карта *узлов переиспользования*. Четыре опоры
  (`SceneVector`, `Hexagram`, `Quest`, `Ecosystem`), на пересечениях которых каждая новая фича = сплав старых
  (E=D×B, K=D×C). Это лучший жанр доки для быстрорастущего репо — мы такой у себя НЕ имеем (надо завести).
- ➕ README густой, с verified-демо и точными `go run ./cmd/…`.
- ➖ **Доковый дрейф (#1 риск):** `REPOSITORY_REVIEW.md` (7 фев 2026) утверждает «📝 стадия документации, **кода
  нет**, 3 файла .md» — прямо противоречит живому состоянию (~120 команд, ~50 пакетов, `go build/test ./...`
  зелёные). Доку не пере-сгенерили — она вводит в заблуждение. Это ровно то, что наш `generate.py --check` +
  pre-commit ловит у нас. Совет: датировать как историческую ИЛИ авто-регенерить статус-секцию.
- ➖ Нет `SECURITY.md`, хотя внешний `BRAIN_URL` = отрисовка/исполнение вывода чужой модели.

# 3. Идея — оценка (для мульти-агентной работы)
- ➕➕ **«Передаём смысл, не пиксели» — сильнейший и прямо-переносимый принцип.** В `raymeet` общий 3-D мир: по
  проводу идёт `Region` (~100–300 Б, раз на регион) + `Pose` (44 Б/тик) + чат/голос; **мир не пересекает провод —
  каждая машина рендерит локально**. Это в точности наш файл-нативный канон: передаём смысл (front-matter+links+
  малое тело), вид пере-собирается локально. TVCP это валидирует на работающем коде.
- ➕ **tvcp-ai/1 «один контракт, меняй URL»** — чистая мульти-агентная абстракция: reference-brain (без модели) /
  Ollama / OpenAI / Anthropic, клиенты не меняются. Robustness уже встроен: retry ×3, валидация легальности хода/
  наличия ops, safe-fallback, **hard-clamp кадра** (чужая модель не раздует фрейм). Это дисциплина, которой нашему
  `thread_runner` не хватает в явном виде.
- ➕ **Детерминизм-от-seed + Go≡Python побайтно** (`SceneVector`/`vector_from_prompt` идентичны) — редкая
  тестируемость: «мозг» и движок говорят на одном словаре, воспроизводимо.
- ➖ **Главный пробел именно для МУЛЬТИ-агентности:** совместность односторонняя — **только host-режиссёр
  авторствует** регионы, гости их реконструируют. `/place crystal` — ко-творение без разрешения конфликтов
  (last-writer на проводе). Несколько режиссёров, конкурентно правящих общий мир, → нужен мёрж/CRDT + кворум-при-
  расхождении. Это ровно то, что мы построили (crdt_merge/seq_merge/oracle_quorum) — обратное опыление туда.
- ➖ Реальный `BRAIN_URL` = один режиссёр = один **захватываемый оракул** (тот же урок, что Q6/verify-once в `.inf`).

# 4. Что ВЗЯТЬ отсюда в наш репо
| из TVCP | к нам |
|---|---|
| **«смысл не пиксели» + raymeet-провод** (Region~100Б / Pose 44Б, локальная пере-сборка) | валидирует канон+`view`; принять дисциплину «тонкая дельта поля → локальная пере-сборка вида», а не пересылку файла |
| **tvcp-ai/1 контракт + robustness** (retry×3, валидация формы, safe-fallback, hard-clamp) | формализовать `thread_runner` как brain-agnostic: один контракт, `BRAIN_URL` любой; добавить валидацию/клэмп вывода |
| **reference-brain без модели** (kind:image/move/draw offline) | расширить наш offline-синтетик до детерминированного reference-ответчика для тестов |
| **CONCEPT_MAP-жанр** (карта хабов переиспользования) | завести `docs/CONCEPT_MAP` для tools/ (view/crdt_merge/seq_merge/canon_index/thread_runner как хабы) |
| **sanitise/clamp вывода модели** | прямо в oracle_quorum/red_team: вывод модели = недоверенный, валидировать/ограничивать, не «verified» |
| **pseudo-diffusion** (grid→upscale→blur→DiffuseFrames) | конкретный рецепт под «псевдо-текстовую/текст-диффузионную» подачу в терминале |

# 5. Что ПОСОВЕТОВАТЬ туда (вашему TVCP)
1. **Доковый дрейф:** регенерить/датировать `REPOSITORY_REVIEW.md` («кода нет» ложно) — авто-статус-секция, как наш `generate --check`.
2. **Истинная мульти-агентность:** ко-авторство общего мира сейчас host-only + last-writer. Дать `Region`-set **OR-Set/LWW-CRDT** (конкурентные place/remove без потери; это тот же класс бага, что я нашёл в `inf_crdt.remove_block` — воскрешение). Несколько режиссёров → кворум-при-расхождении (наш oracle_quorum).
3. **Видимость оракула:** один `BRAIN_URL`-режиссёр захватываем; для высоких ставок — кворум мозгов с *видимым* расхождением, авторитет режиссёра явный и оспоримый.
4. **SECURITY.md + threat-model адаптеров:** sanitise/clamp есть (отлично) — задокументировать модель угроз «вредоносный BRAIN_URL», распространить на chat/voice путь (dedup уже есть).
5. **Q6 позиционирование:** теперь честно используется как **детерминированный адрес/словарь** (Go≡Python), не как обученный эмбеддинг — так и держать; Block-M (нуклеарная/реверс, 3 аттрактора) — изящная структура/арт, не семантика.

# 6. Вердикт
**Живой svend4/infon — это ваш TVCP: серьёзная, работающая Go-платформа, куда впитаны Q6/pseudo-diffusion/
swap-brains из `.inf`.** Сильнейшее к переносу к нам — **«смысл, не пиксели»** (raymeet) + **tvcp-ai/1 robustness-
контракт**. Сильнейший совет туда — **достроить мульти-агентность**: общий мир пока host-only/last-writer; дать ему
CRDT-мёрж + кворум-при-расхождении (ровно наш T-263-инструментарий). Двусторонний урок прежний: семантика упирается
в LLM-оракула — у TVCP это единственный `BRAIN_URL`-режиссёр; делать его **видимым и кворумным**, а не единоличным.
