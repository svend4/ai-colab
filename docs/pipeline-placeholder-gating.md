# Pipeline placeholder gating

Дата: 2026-06-20

Статус: кодовая правка подготовлена, runtime-приёмка заблокирована `T-039`.

## Проблема

После синхронизации конвейера `T-062`, `T-063` и `T-064` стали видны как `ready`, потому что формально имели:

- `status: todo`;
- пустые зависимости;
- отсутствие свежего claim.

Но их заголовок `(зарезервировано — заполните)` означает, что это не настоящие проектные задачи, а пустые резервы. Если оставить их в ready queue, автоматический агент может занять пустую задачу, создать шумный done-marker и исказить историю работ.

## Изменение

В `tools/pipeline.py` добавлен guard:

```python
def is_placeholder_task(t):
    title = (t.get("title") or "").strip()
    return title == "(зарезервировано — заполните)"
```

Теперь placeholder-задачи:

- не попадают в `ready_sorted()`;
- не выдаются через `python tools/pipeline.py next <agent>`;
- в `build_pipeline_state()` отображаются в blocked/not-ready с причиной `placeholder task`.

## Почему так

Резервный ID - это ещё не задача. Для большого числа людей и агентов важно различать:

- `todo` как настоящую задачу, которую можно брать;
- `todo placeholder` как техническую заготовку, которую сначала надо заполнить;
- `blocked` как настоящую задачу, которую нельзя выполнить из-за внешнего условия.

Эта правка не меняет `tasks/T-062.md`, `tasks/T-063.md`, `tasks/T-064.md`, потому что они принадлежат Claude как резервы. Она меняет только поведение диспетчера: пустые резервы больше не должны попадать в автоматическую раздачу.

## Проверка после восстановления runtime

После снятия `T-039` нужно выполнить:

```text
python tools/pipeline.py status
python tools/pipeline.py snapshot
python tools/pipeline.py next codex
```

Ожидаемый результат:

- `status` показывает `T-062`, `T-063`, `T-064` как `placeholder task`;
- `snapshot` обновляет `PIPELINE.md` и `logs/pipeline.json` без ready-placeholder;
- `next codex` не занимает `T-062`, `T-063`, `T-064`.

Если в котле нет других настоящих ready-задач, `next` должен вернуть сообщение, что готовых задач нет.
