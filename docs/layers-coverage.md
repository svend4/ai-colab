## Вывод

Сильные слои — **L0, L4, L7** (основание, агенты, оркестрация — это и есть инфраструктура, которую построили). Зрелый «средний слой» упирается в **L2 (MCP-драйверы)** и **L6 (память/SQLite)** — оба сейчас на стадии «карта/дизайн без реализации».

**Рекомендуемый порядок (right-size, по D-010):**
1. **L2 — первый read-only MCP-драйвер** (`files`): превращает `drivers/files.md` из манифеста в реальный инструмент. Кандидаты — в `docs/l2-candidates.md` (T-033).
2. **L6 — реализовать `workbench.db`** (SQLite по схеме T-031): даёт повторяемый поиск/отчётность; `repo-runner/inventory.py` уже выдаёт нужную структуру.
3. **L1 — WSL2+Docker** только когда дойдём до запуска непроверенного кода Sven4 (песочница).
