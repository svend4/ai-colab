## Этап 4. C33 safe_write миграция (30–60 мин) — ИНФРАСТРУКТУРА

**Цель:** каждый инструмент, пишущий в канон-пути, использует `safe_write`.

1. **T-272** — по одному файлу из WRITE_ALLOWLIST:

   - Проверять `adoption.py` после каждого изменения.

2. Порядок: от простого (generate.py — уже генерат) к сложному (pipeline.py — runtime-очередь).

**Результат:** все канон-писатели либо `safe_write`, либо явно помечены.
