# Agent policy scope review — 2026-07-06

Автор: Codex  
Статус: review / proposed interpretation

## Вывод

В проверенной политике репозитория не найдено общего правила "агент может делать только маленькие технические правки".

Фактическая политика:

1. Маленькие механические правки имеют быстрый маршрут: trace + проверка, без полного котла.
2. Большие концептуальные, методологические, архитектурные и программные предложения разрешены как `proposed`: report/topic/stream/draft decision/task/question.
3. Спорное или governance-значимое не становится `accepted` без человека или явно назначенного сборщика.

## Практическая формула

- `small/mechanical/checkable` -> scoped edit -> checks -> outbox/trace -> done.
- `large/conceptual/disputed` -> свой полный вариант -> сверка с другими -> consensus/divergence -> proposed decision/task -> human/appointed ratification.
