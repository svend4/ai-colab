# T-273 L2 payload — первый живой груз AI-OS Bridge

Первый живой L2-груз замкнутого контура отработан end-to-end на реальных данных
(read-only). Груз: инвентаризация внешней папки-бэкапа проекта через новый
read-only инструмент `tools/l2_inventory.py` (переиспользование паттернов
`file-inventory` / `text_extract` / `canon_index`), с FTS5-индексом и
redaction. Источник строго read-only, внешний код не исполнялся.

Это отчёт такта W_report + scribe единого цикла из
`reports/t273-pilot-divergence-reconcile-2026-07-06.md`:

```
W_safety (route/safety boundary)  ->  GATE (go/no-go)
  ->  W_build (l2_inventory.py)  ->  W_run (реальный источник)
  ->  W_verify x2 (независимо)  ->  W_report + scribe   <-- этот отчёт
```

## 1. Маршрут (что и как прошло)

| Такт | Роль | Итог | Артефакт |
|---|---|---|---|
| W_safety / GATE | safety | go=true для read-only маршрута; NO-GO для внешнего execute/clone/install | `reports/T-273-l2-pilot-safety-gate-2026-07-06.md`; SAFETY-блок пилота |
| W_build | builder | `tools/l2_inventory.py` + тест собраны, зелёные, `validate.py` ERROR=0 | `tools/l2_inventory.py`, `tools/tests/test_l2_inventory.py` |
| W_run | runner | build+stats+query на реальном источнике; источник неизменён | `tmp-work/t273/backup.db` |
| W_verify A | verifier | воспроизвёл счётчики, sha256 снимка источника до/после совпал | `tmp-work/t273/verify_A.db` + снимки |
| W_verify B | verifier | воспроизвёл счётчики независимо, cross-check содержимого файлов | `tmp-work/t273/verify_B.db` |

Ключевые решения маршрута:

1. **Переиспользование, не переписывание** (SAFETY §1): базовый паттерн —
   `drivers/file-inventory/inventory.py` (T-059, read-only `os.walk`, confinement
   через `relative_to`), текст — `tools/text_extract.py` (redact=True,
   MAX_EXTRACT_CHARS=20000), FTS — `tools/canon_index.py` (stdlib sqlite3 FTS5 с
   деградацией к LIKE). Новый `tools/l2_inventory.py` не трогает
   `files.md`/`sqlite.md`/`text_extract.py`/`canon_index.py`.
2. **Источник — сиблинг репозитория** (не внутри него):
   `C:\Users\stefan\Documents\ai-colab-backup-2026-06-24`. Confinement через
   `--source` (candidate.relative_to(root)); `--db` внутри `--source` запрещён
   конструктивно (`resolve_db_path` → `PathAccessError`).
3. **Запись только в `tmp-work/t273/`** — БД/JSON; источник строго read-only.
4. **Git-бандл не распаковывается**: `ai-colab-full-repo.bundle` (2.7 МБ)
   классифицирован как бинарь (`is_text=0`), в FTS не индексируется, читается
   только по метаданным.

## 5. ОСОБО: отставание бэкапа от канона (ответ Q-a)

Это главный содержательный результат пилота, а не только демонстрация механики.

**Бэкап 2026-06-24 отстаёт от текущего канона на две волны работы.** Все 121
канон-файла текущего репо (после исключения копий в `.claude/worktrees/*`)
**отсутствуют** в файловом инвентаре бэкапа:

| Семейство канона | Файлов отсутствует | Что именно |
|---|---|---|
| `decisions/D-029..D-035` | 7 | решения после 06-24 |
| `reports/audit-*` | 37 | `audit-claude-2026-06-26/-07-02` (.md+.json), `audit-fix-wave1-handoff-2026-07-02.md`, ~34 машинных `audit_YYYYMMDD_*.json` (06-24..07-05) |
| `tasks/T-200..T-276` | 77 | задачи волны 2xx |
| **Итого** | **121/121 missing** | |

**Причина** структурная, не потеря данных: бэкап от 2026-06-24 хранит **поток
`queues/outbox`**, а не отдельные канон-файлы. Вся более поздняя работа
(аудит-волны 1/2 за 06-26..07-05, задачи T-2xx, решения D-029+, butterfly-граф)
в него не входит **по определению снимка**.

**Оговорка целостности:** часть этой истории может физически присутствовать
внутри `ai-colab-full-repo.bundle` (git-бандл), но как бинарь он **не
индексируется в FTS** и не даёт файлового соответствия — подтвердить/опровергнуть
через данный read-only инструмент нельзя (для этого нужен отдельный
`git-log`/`repo-runner` над бандлом, а он вне первого пилота).

**Ловушка сравнения (зафиксирована для повторяемости):** первый прогон дал
ложные 189 «совпадений» из-за копий канона внутри
`.claude/worktrees/friendly-turing-7181df`. Корректное сравнение исключает
`.git`, `tmp-work`, `.claude` из обхода репо.

## 6. Ограничения (лимиты, read-only, no-execute)

**No-execute / read-only источника:**

1. Найденные `.py/.exe/.bat/.sh` **не запускались**; git-бандл **не**
   распаковывался (`git clone`/`bundle unbundle` не выполнялись).
2. Нет сети/fetch/clone; нет `pip`/`npm`/build/test внешнего кода.
3. Источник открыт только на чтение (`os.walk`, `stat(follow_symlinks=False)`,
   `open(path,"rb")`); ни одной мутации по путям источника в коде инструмента
   (проверено обоими верификаторами: нет `remove/unlink/rename/replace/shutil/
   open('w')/truncate`). Symlink/reparse-точки пропускаются, не следуются.
4. Все записи — только `tmp-work/t273/` (БД/JSON); `--db` внутри `--source`
   запрещён конструктивно (`PathAccessError`).

**Лимиты (защита от раздувания памяти/логов):**

| Параметр | Значение | Где |
|---|---|---|
| `max_files` | 1000 | inventory |
| `read_file max_bytes` | 1 МБ | чтение файла |
| `MAX_EXTRACT_CHARS` | 20000 | text_extract |
| `max_hash_bytes` | 10 МБ | хеш |
| whitelist текста | `.md` / `.json` | extract/FTS |

Крупнейший текстовый файл — 20 КБ, весь источник — 3.5 МБ; риск раздувания
минимален. Бинарь (бандл 2.7 МБ) в память как текст не читался.

**Секреты/приватность:** redaction (`SECRET_RE` + `AWS_KEY_RE`, маскировка
`$HOME`/`$WORKSPACE`) обязателен на всём тексте, идущем в отчёт/БД. Реальных
кредов не найдено (0 AKIA/IBAN/passport/SSN); 8 упоминаний
`secret/token/password/bearer` — это policy-обсуждения, не голые ключи. Значения
секретов не печатаются даже при находке.

**Косметика (не влияет на данные):** скобки `[ ]` в сниппетах `query` — это
разделители подсветки `snippet(files, …, '[', ']', …)`, а не содержимое файла.
