# Bridge Glossary

| Term | Meaning |
|---|---|
| bridge | Middle layer connecting people, agents, drivers, and reports. |
| claim | Visible lease that says who is working on a task. |
| report | Markdown artifact that can be reviewed asynchronously. |
| corpus | Local set of files used by the knowledge workflow. |

The word `bridge` is intentionally repeated so query tests can find this file.
