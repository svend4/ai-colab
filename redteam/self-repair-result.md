### meaning-not-string ✅
**Отремонтированная формулировка:** И-«смысл, не строка» (починенный, согласован с И-3/И-4): Тождество узлов определяется СМЫСЛОМ, а не строкой/автором/временем — но это правило работает ТОЛЬКО как одностороннее исключающее, и НИКОГДА как правило слияния по умолчанию. (а) Единица тождества — ПОЛНАЯ нормальная форма: кортеж <тезис · область-условие · класс-evidence · риск · путь-обоснования · независимый свидетель>, а НЕ проекция на один тезис. Идентичность по любой ОДНОЙ координате (в т.ч. по тезису) тождества НЕ влечёт. (б) Что правило РАЗРЕШАЕТ (негативная, безопасная сторона): голое СТРОКОВОЕ различие — перефраз, синоним, перевод, другой автор/время — само по себе НЕ создаёт новый узел и не даёт лишнего свидетеля. Лексическое несовпадение не есть доказательство РАЗЛИЧИЯ по смыслу. (Это и закрывает провал чисто-лексического dedup: §8 котла — лексика дала 0 ядра, смысл 9.) (в) Что правило ЗАПРЕЩАЕт (защита от эксплойта): совпадение по СМЫСЛУ тезиса само по себе НЕ создаёт право на слияние. Презумпция — РАЗЛИЧИЕ узлов, бремя на «это дубль» (наследуется прямо из И-3). Два кандидата схлопываются в один узел ТОЛЬКО если пройден lossless-гейт слияния: ни один не теряет НИ уникального условия, НИ evidence, НИ риска, НИ пути, НИ открытого вопроса (тест И-3 «шум только если не добавил нового»), И слияние не уничтожает независимого свидетеля (защита И-4: разные источники≠дубликат вывода). (г) Минор-кламинг неустраним «по смыслу»: если кандидаты совпали по тезису, но различаются хоть по одной несущей координате (б/в) — это НЕ дубль, а scope-ветвь или со-узел; при сомнении — открытая развилка/оба сохраняются, НЕ молчаливое слияние (наследует И-5/И-7). Ядро сохранено: id — по смыслу, не по тексту; чисто-строковый dedup отвергнут. Но «перефраз = тот же узел» переформулировано в «перефраз сам по себе ≠ новый узел И сам по себе ≠ право на слияние» — тождество требует совпадения ВСЕЙ нормальной формы и прохождения lossless-гейта, а не одного тезиса.

**Почему держится:** Исходная дыра закрыта: ремонт расщепляет двунаправленное «идентичность смысла ⇔ один узел» на два односторонних правила. ### falsifiability ✅
**Отремонтированная формулировка:** Фальсифицируемость (типизированная по классу claim): каждый claim несёт ДИСКРИМИНИРУЮЩЕЕ УСЛОВИЕ ОПРОВЕРЖЕНИЯ, форма которого задаётся его классом, объявленным ДО red-team: (A) Эмпирический claim (о фактах/мире) — условие = предсказательный тест: наблюдение/прогон, исход которого при ложности claim отличается от исхода при истинности. Закрывается только провалом такого теста; без него — открытая развилка, не закрывается большинством. (B) Нормативно-методический claim (о том, как вести метод: правила, гейты, инварианты процесса) — условие = ДЕМОНСТРИРУЕМЫЙ КОНТРПРИМЕР-ОТКАЗ: конкретный сценарий/прогон, в котором следование правилу даёт named failure mode (несвязность с другими инвариантами, эксплойт, регресс, само-аннуляция). Для класса B «дискриминирующий тест» = адверсариальная демонстрация вреда/противоречия, НЕ эмпирический эксперимент; обоснование — связностью корпуса и предотвращаемым отказом, а не предсказанием о мире. Мета-правило применимости (закрывает само-референцию): сам этот инвариант принадлежит классу B и судится по критерию B. Он остаётся в каноне, ПОКА red-team не предъявил для него работающий контрпример-отказ; предъявленный контрпример (как self-exclusion-атака) есть именно тот опровергающий тест, который правило требует, — поэтому инвариант фальсифицируем по своему же стандарту и не выводит сам себя в pending. Class-mislabel сам опровержим: если claim класса B на деле проверяем эмпирически (или наоборот), это named failure mode → refuted. Любой claim без объявленного класса и без условия опровержения соответствующей классу формы → pending (не урезание «по нефальсифицируемости вообще», а требование указать ПРАВИЛЬНУЮ форму теста).

**Почему держится:** Исходная дыра (САМОИСКЛЮЧЕНИЕ) закрыта структурно. Она держалась на ОДНОМ допущении: «единственный валидный дискриминирующий тест — эмпирический». Ремонт вводит ТИПИЗАЦИЮ: класс B (нормативно-методический) судится демонстрируемым контрпримером-отказом, а не экспериментом. Поэтому инвариант теперь НЕСЁТ условие опровержения формы своего же класса → перестаёт быть «нефальсифицируемым по своему правилу» → red_team_gate его НЕ маршрутизирует в pending. Важно: я проверил реальный tools/red_team_gate.
